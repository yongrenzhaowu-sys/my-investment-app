### フェーズ4: 理論株価×モメンタム複合戦略 ⭐️

**ユーザーの提案**:
「カスタム成長率を用いて来期理論株価を計算し、現株価との乖離が大きいものを並べ、そのうちからモメンタム指標の高い銘柄を購入する」

**実装**:
1. 理論株価 = 来期EPS × 四半期PER
2. 乖離率 = (理論株価 - 現株価) / 現株価
3. 割安銘柄（乖離率 > 0）を抽出
4. その中から6Mリターン上位20銘柄を選択

**結果**: 🎉 **大成功！**
- 年率: **+34.88%**（ベースライン比 +9.27%pt）
- シャープ: 1.07（ベースラインと同じ）
- MDD（リバランス時点）: -1.10%
- 勝率: 87.5%

## 重要な学び

### 1. 理論 vs 実践

**失敗例**:
- R2補正: 理論的に優れているが実際は有害（-2.96%）
- tanh(slope/sigma): 外国株では有効だが日本株では失敗（+1.65%）

**成功例**:
- 理論株価×モメンタム: シンプルだが効果的（+34.88%）

### 2. 組み合わせの力

**単体戦略の限界**:
- バリュー単体: 割安だが上がらないリスク
- モメンタム単体: 高値掴みのリスク

**組み合わせの効果**:
- ファンダメンタル + バリュー + モメンタム = 最強

### 3. 日本株の特性

- 中期モメンタムが弱い
- slope/sigma比が低い（0.1～0.3）
- バリュー戦略が効果的

### 4. バックテストの限界

- リバランス時点のMDDは過小評価
- 日次MDDは-20%～-30%程度（推定）
- 実運用コスト（手数料、税金、スリッページ）を考慮
