## 学んだこと

### 1. 日次評価の重要性

**問題**:
- 年次評価版: MDD -2.41%（過小評価）
- 日次評価版: MDD -27.70%（正確）

**教訓**:
- 年に1回しか評価しないとドローダウンを見逃す
- 正確なリスク評価には日次データが必須
- ポートフォリオ最適化には正確なMDDが必要

### 2. ベース戦略のMDDが予想より低い

**ユーザー予想**: -35%程度
**実際の結果**: -27.70%

**理由**:
- ベース戦略（低PBR×高ROE）の安定性
- 年次リバランスによる低回転率
- 20銘柄分散による効果

**影響**:
- 全ての配分でMDD -30%以下を達成可能
- より攻撃的な配分（Base20_Lev80）でも目標達成

### 3. ポートフォリオ分散の威力（再確認）

**レバレッジ戦略単体**:
- 年率+30.68%, MDD -42.08%, Sharpe 1.076

**Base20_Lev80**:
- 年率+33.27%, MDD -19.75%, Sharpe 1.641

**効果**:
- MDD -22.33%削減
- Sharpe +0.565改善
- リターン +2.59%向上

**教訓**: ポートフォリオ分散は全指標で改善（ノーフリーランチではない！）

### 4. シャープレシオの劇的改善

**配分比率とシャープレシオの関係**:
- Base20_Lev80: Sharpe 1.641
- Base50_Lev50: Sharpe 1.862
- Base80_Lev20: Sharpe **2.024**（驚異的）

**教訓**:
- ベース配分を増やすほどシャープレシオ向上
- ベース戦略の低ボラティリティが効く
- リスク調整後リターンを重視するならBase80_Lev20

### 5. データ処理の注意点

**問題**:
- Period型のCSV保存で整数に変換される
- Unicodeエラー（絵文字）
- 銘柄コードのデータ型不一致

**対応**:
- 日次データから直接月次リターンを再計算
- 絵文字を使わない（Windows cmd.exe対応）
- データ型を明示的にチェック
