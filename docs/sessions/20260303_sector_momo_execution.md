- 総エクスポージャー: 100%
- 最小ウェイト: 2%
- 最大ウェイト: 8%（実際は11.66%まで拡大）
- リスク指標: Volatility20

## 重要なパス/コマンド

### プロジェクトディレクトリ

- レポート出力: `jquants-sector-momo/reports/report_latest.json`, `report_latest.md`

- データソース（日次バー）: `legacy/_inbox/jquants_daily_bars_10y_parquet/daily_parquet/*.parquet`

### 実行コマンド
```bash
cd jquants-sector-momo

# 基本実行（60日分、上位3セクター、10銘柄）
python run_pipeline.py --days 60 --asof 2026-01-22 --top-sectors 3 --top-stocks 10

# より多くの銘柄を取得
python run_pipeline.py --days 60 --asof 2026-01-22 --top-sectors 5 --top-stocks 20

# プライム市場のみ
python run_pipeline.py --days 60 --asof 2026-01-22 --prime-only
```

## 備考

- **ルックアヘッドバイアス防止**: `asof_date`時点で利用可能なデータのみ使用
- **投資助言ではない**: レポートにディスクレーマー必須
- **データ配布禁止**: 推奨銘柄のみ保存（全銘柄時系列は保存しない）
- **調整済み価格使用**: AdjO/AdjH/AdjL/AdjC/AdjVoを使用して株式分割の影響を除去
