## 発見したこと

### 戦略のミスマッチ
現在のポートフォリオと推奨銘柄には**大きなギャップ**があります：

**現在のポートフォリオ**:
- 長期保有型の大型株・総合商社・機械株中心
- 含み益が大きい（平均+48%）
- セクター分散型

**推奨銘柄（短期モメンタム戦略）**:
- 非鉄金属・精密機器・電気機器に集中
- 直近20日で+50〜+140%の急騰銘柄
- セクター集中型（上位3セクターで90%以上）

### 保有銘柄が推奨外となった理由
1. **戦略の違い**: ユーザーのポートフォリオは長期保有型、推奨戦略は短期モメンタム型
2. **セクター分類の問題**: データ上で「不明」と表示（マスターデータとの不一致の可能性）
3. **流動性フィルター**: 一部の保有銘柄は流動性が低く、戦略の対象外
4. **モメンタムの違い**: 直近20日のモメンタムが低い

## 決めたこと

### 提案の方向性
単純な「全銘柄売却 → 全銘柄購入」は推奨しない。理由：

1. **税金の影響**: 含み益+48%に対する税金（約20%）を考慮すると、実効コストが大きい
2. **投資スタイルの違い**: 短期モメンタム vs 長期保有
3. **リスクの違い**: 推奨銘柄は高ボラティリティ

### 推奨アプローチ（3つの選択肢）

#### オプション1: 現状維持 + 部分的追加
- **メリット**: 税金を繰り延べ、既存の含み益を保持
- **行動**: 新規資金で推奨銘柄を少量追加（1〜2銘柄）
- **向いている人**: 長期保有派、税金を避けたい

#### オプション2: 段階的な組み替え
- **メリット**: リスク分散、税金の平準化
- **行動**:
  1. 含み損・低パフォーマンス銘柄を優先売却（70820ジモティー、47650SBIグローバル）
  2. 売却資金で推奨TOP 3を購入（77190東京衡機、58170ＪＭＡＣＳ、57270東邦チタニウム）
  3. 2〜3ヶ月かけて徐々に組み替え
- **向いている人**: リスクを取りつつ、慎重に移行したい

#### オプション3: 完全組み替え（短期モメンタム戦略への転換）
- **メリット**: 戦略の一貫性、最大リターンの追求
- **デメリット**: 税金コスト（約58万円）、高ボラティリティ
- **行動**: 全12銘柄売却 → 推奨TOP 10購入
- **向いている人**: 短期トレーダー、高リスク許容度
