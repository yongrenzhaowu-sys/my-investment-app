## 🔧 発見した問題点

### 問題1: 初期資金設定が保存されない
- **現状**: セッション状態で管理（ログインごとに1,000,000にリセット）
- **原因**: `st.session_state.initial_capital` はブラウザセッションのみ
- **解決策**: settings.jsonに永続化

### 問題2: 部分売却ができない
- **現状**: 売却時に全株売却のみ
- **解決策**: 売却数量フィールドを追加、残株数を計算

### 問題3: 投資指標がない
- **現状**: アルファとリターンのみ
- **要望**: シャープレシオ、最大ドローダウン、勝率など
- **解決策**: 投資指標計算モジュールを追加

### 問題4: NISA口座に対応していない
- **現状**: すべて課税口座として扱われる（税率20.315%）
- **要望**: NISA口座は税金0%
- **解決策**: is_nisaフィールド追加、税金計算を条件分岐

### 問題5: 銘柄名が表示されない
- **現状**: 銘柄名が表示されていない（「銘柄XXXXX」と表示）
- **原因**: API呼び出しの失敗、またはレスポンス処理の問題
- **解決策**: get_company_info()の修正、エラーハンドリング強化

**実装する指標**:
1. **シャープレシオ**

2. **最大ドローダウン**
   - 最高値からの最大下落率

4. **平均保有日数**

5. **累計リターン**
   - (現在評価額 + 累計売却額) / 初期資金 - 1
