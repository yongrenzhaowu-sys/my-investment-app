### 2. 実装の特徴

#### 2.1 プリセット期間
- 1ヶ月、3ヶ月、6ヶ月、1年から選択可能
- カスタムで任意の期間を指定可能

#### 2.2 加重方法
- **等加重**: セクター内の全銘柄の平均リターン（シンプル、高速）
- **時価総額加重**: セクター内の時価総額加重平均リターン（より正確）

#### 2.3 可視化
- Plotlyのバーチャートで相対リターンを可視化
- 色分け（緑=強い、赤=弱い）
- 高さ順ソート

#### 2.4 エラーハンドリング
- APIエラーをキャッチして表示
- トレースバックを表示（デバッグ用）
