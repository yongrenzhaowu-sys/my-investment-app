## 🚧 制約・注意点

### データ制約
1. **財務データ不足**: 2025-07-25以降のデータが取得できず
   - **原因**: J-Quants API V2のレート制限（HTTP 429エラー）
   - **影響**: CMAファクターが計算できない（すべて0）
   - **対策**: 複数日に分けて取得、またはプラン変更を検討

2. **営業日の簡易判定**: 土日除外のみ、祝日考慮なし
   - **影響**: データ未取得日が17日（270-253=17日）

### 分析制約
1. **短期間分析**: 6ヶ月間のみの結果
   - 統計的有意性は限定的
   - 長期トレンドとは異なる可能性

2. **ルックアヘッドバイアス**: 完全防止を確認
   - t月末終値でシグナル → t+1月初始値でエントリー
   - 財務データは開示日ベースで制御

## 🎓 学んだこと

### J-Quants API V2の実践知
1. **日次バッチ取得が最速**: `date`パラメータのみで全銘柄取得可能
2. **実測所要時間**: 株価4秒/日、財務0.12秒/日
3. **レート制限**: 100リクエスト程度で429エラー発生の可能性

### ファクター分析の実務知
1. **市場環境は短期間で激変**: 6ヶ月で有効ファクターが逆転
2. **複数期間での検証必須**: 単一期間の結果を過信しない
3. **モメンタムの強さ**: 日本市場でもモメンタムファクターは有効

### データ取得の教訓
1. **順次処理の信頼性**: 並列処理より遅いが確実
2. **エラーログの重要性**: 失敗日を記録して後で再取得
3. **部分成功の活用**: 完全取得できなくても分析は可能
