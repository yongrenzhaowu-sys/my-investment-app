# セッションサマリー: 月足最安値R2仮説の検証

**日時**: 2026-02-21 23:00～
**目的**: 書籍に記載された「過去3ヶ月の月足最安値でR2 >= 0.98なら次月上昇」という仮説を検証

---

## やったこと

### 1. 統計分析の実施

**スクリプト**: `analyses/20260221_2300_monthly_low_r2_validation/01_statistical_analysis.py`

**内容**:
- 月次最安値データを集計（2016-2026年、約50万サンプル）
- 過去3ヶ月の最安値で線形回帰を実施してR2を計算
- R2 >= 0.98の銘柄の次月リターンを分析
- 統計的有意性をt検定で確認

**結果**:
- R2 >= 0.98の該当率: 14.39%
- 平均次月リターン: 1.06%（比較群0.92%より+0.14%pt高い）
- t統計量: 2.976（統計的に有意、p < 0.05）
- **結論**: 統計的には有意だが、効果は極めて小さい

### 2. バックテストの実施

**スクリプト**: `analyses/20260221_2300_monthly_low_r2_validation/02_backtest_monthly_r2.py`

**戦略**:
- リバランス: 月次
- 選択基準: R2 >= 0.98、slope上位20銘柄
- 期間: 2016年4月～2025年12月（9.7年間）

**結果**:
- 年率リターン: **-31.25%**（壊滅的失敗）
- 総リターン: -97.33%（1,000万円→26万円）
- 勝率: 8.6%
- 最大DD: -97.37%

**問題点**:
- 2021年以降、ほとんどの月で銘柄数0（取引不可）
- 2016年初期に連続大損失（-42.75%, -31.97%, -29.78%）
- 2020年5月に-60.18%の壊滅的暴落

## 決めたこと

### 仮説の最終評価: ❌ 完全に誤り

**書籍の仮説**:
「過去3ヶ月の月足最安値でR2 >= 0.98なら次月上昇」

**検証結果**:
- ✅ 統計的には有意（+0.14%pt）だが、効果は微弱
- ❌ 実際の投資戦略としては壊滅的失敗（年率-31.25%）
- ❌ 実用性: 完全に不可

### なぜ失敗したのか

1. **統計とバックテストの乖離**
   - 統計: 全銘柄の平均（+1.06%）
   - バックテスト: slope上位選択（-31.25%）

2. **選択ルールの致命的欠陥**
   - 高R2 × 高slope = 急騰後の銘柄を選択
   - これらは天井圏にあり、次月は反落する

3. **取引機会の不足**
   - R2 >= 0.98は条件が厳しすぎる
   - 大半の月で銘柄数0

### 推奨事項

❌ **やめるべきこと**:
- R2 >= 0.98の条件で銘柄選択
- 月足最安値のslopeで銘柄選択
- この仮説に基づく投資

✅ **代わりに推奨**:
- 理論株価×モメンタム複合戦略（前回確定、年率+34.88%）
- ファンダメンタル重視のバリュー戦略（低PBR×高ROE、年率+25.61%）

## 重要な学び

### 1. 統計的有意性 ≠ 実用性

- p < 0.05でも、効果が0.14%ptでは実用不可
- 取引コストを考慮すると、1～2%ptの差が必要

### 2. 選択ルールの重要性

- 同じ条件でも、選択ルールで結果が劇的に変わる
- slope上位選択は、急騰後の暴落を選んでいた

### 3. バックテストの必要性

- 統計分析だけでは不十分
- 実際の投資戦略をシミュレーションしないと真の性能は分からない

### 4. 書籍の情報は検証が必須

- 権威ある書籍でも誤りがある
- 必ず自分でバックテストして検証すべき
