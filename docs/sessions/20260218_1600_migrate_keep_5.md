- 内容未確認の場合: 汎用テンプレート + TODO明記（1月29日・21日）

- **絶対に移動・削除しない**（CLAUDE.md遵守）

- 原本は参照用として保持

- idea_XX.md と analysis_XX.ipynb は1:1対応
