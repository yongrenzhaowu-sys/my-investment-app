## 決めたこと

### バグの原因特定
**しきい値ベースリバランスの欠陥**:
- ポートフォリオ重複率70%以上でリバランスをスキップする機能
- リバランスをスキップすると、ポートフォリオの価格情報が更新されない
- 古い価格で計算が継続され、異常なリターンが発生
- このロジックは使用不可と判断

### 正式版の設定
- **リバランス**: 毎週必ず実行
- **ウェイト**: 均等ウェイト
- **ボラティリティベースウェイト**: 無効化

## 学んだ教訓

1. **リバランススキップ機能は要注意**
   - 取引コスト削減のためのスキップロジックは、価格更新を含めて慎重に実装する必要がある
   - 今回のケースでは、ポートフォリオの価格情報が更新されないまま計算が継続され、異常値が発生

2. **異常値は必ず原因を追求する**
   - 年率4000-7000%という数値は明らかに異常
   - リバランス実行率7.8%という統計から原因を特定できた

3. **段階的なデバッグが有効**
   - ボラティリティウェイト無効化 → 依然として異常
   - リバランス閾値無効化 → 正常化
   - この手順で真の原因を特定できた

4. **高速化は重要**
   - 2分で実行できるようになったことで、試行錯誤が可能になった
   - ピボットテーブル化は効果的
