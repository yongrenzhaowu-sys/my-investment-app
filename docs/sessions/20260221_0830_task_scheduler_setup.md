2. **Python実行パスの確認**:

3. **手動実行テスト済みであること**:

### トラブルシューティング

#### 問題1: タスクが実行されない

**確認事項**:
1. タスクスケジューラで「最後の実行結果」を確認
   - `(0x0)`: 成功
   - `(0x1)`: 一般的なエラー
   - `(0x41301)`: タスクが現在実行中
   - その他: エラーコードでGoogle検索

2. トリガーが「有効」になっているか確認

3. PCが起動しているか確認（スリープ状態では実行されない）

**対処**:
- プロパティ → 設定タブ → 「タスクを実行するためにスリープを解除する」にチェック

#### 問題2: タスクは実行されるがエラーになる

**確認事項**:
1. ログファイルを確認:
   ```cmd
   type logs\daily_run.log
   ```

2. 環境変数が読み込まれているか確認
   - Task Schedulerは独自の環境で実行されるため、ユーザー環境変数が読み込まれないことがある

**対処**:
- プロパティ → 操作タブ → プログラムをフルパスで指定
- システム環境変数に `JQUANTS_API_KEY` を設定（ユーザー環境変数ではなく）

#### 問題3: 手動実行は成功するが、スケジュール実行は失敗する

**原因**:
- 作業ディレクトリが正しく設定されていない

**対処**:
- プロパティ → 操作タブ → 「開始（オプション）」に以下を設定:
  ```
  C:\Users\yongr\claude project\workspace
  ```

#### 問題4: 環境変数エラー

**エラー**: `JQUANTS_API_KEY environment variable is not set`

**対処**:
1. システム環境変数に設定:
   - Windowsキー → 「環境変数」で検索
   - 「システム環境変数の編集」を選択
   - 「システム環境変数」セクションで「新規」
   - 変数名: `JQUANTS_API_KEY`
   - 値: `<実際のAPIキー>`
   - OK で保存
   - PCを再起動

2. または、バッチファイル経由で実行:
   - `scripts/daily_run.bat` を作成:
     ```batch
     @echo off
     cd /d "C:\Users\yongr\claude project\workspace"
     set JQUANTS_API_KEY=<実際のAPIキー>
     python scripts\daily_run.py
     ```
   - Task Schedulerで `scripts\daily_run.bat` を実行

### 代替方法: バッチファイル経由（推奨）

環境変数の問題を回避するため、バッチファイル経由での実行を推奨します。

#### バッチファイル作成

`scripts/daily_run_scheduled.bat` を作成:

```batch
@echo off
REM 日次自動化システム - Task Scheduler用バッチファイル

REM 作業ディレクトリに移動
cd /d "C:\Users\yongr\claude project\workspace"

REM 環境変数設定（システム環境変数が使えない場合のフォールバック）
REM 注意: APIキーは絶対にリポジトリにコミットしない
if "%JQUANTS_API_KEY%"=="" (
    echo ERROR: JQUANTS_API_KEY is not set
    exit /b 1
)

REM Python実行
python scripts\daily_run.py

REM 終了コードをそのまま返す
exit /b %ERRORLEVEL%
```

#### Task Schedulerでバッチファイルを実行

- **プログラム/スクリプト**: `cmd`
- **引数**: `/c "C:\Users\yongr\claude project\workspace\scripts\daily_run_scheduled.bat"`
- **開始**: （空欄でOK）

## 参考情報

### タスクスケジューラのエラーコード

| コード | 意味 |
|--------|------|
| 0x0 | 成功 |
| 0x1 | 一般的なエラー |
| 0x2 | ファイルが見つからない |
| 0x41301 | タスクが現在実行中 |
| 0x41303 | タスクがまだ実行されていない |
| 0x800710E0 | タスクが実行されたが、正しく終了しなかった |

### Python実行エラー

スクリプト内のエラーは `logs/daily_run.log` に記録されます。

### Windows環境での注意点

- パスにスペースが含まれる場合は必ず **ダブルクォート** で囲む
- バックスラッシュ `\` を使用（スラッシュ `/` ではない）
- コマンドプロンプトとPowerShellで環境変数の参照方法が異なる:
  - コマンドプロンプト: `%JQUANTS_API_KEY%`
  - PowerShell: `$env:JQUANTS_API_KEY`
