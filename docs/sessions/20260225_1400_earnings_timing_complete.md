## 決めたこと

### 主要発見

#### 1. 相関係数は1週間が最も高い
- **小型株（Q1）**: 1週間=+0.0422、1ヶ月=+0.0221、2ヶ月=+0.0242
- **中型株（Q3）**: 1週間=+0.0524（最高）
- **大型株（Q4）**: 1週間=+0.0337、2ヶ月で大幅低下（+0.0108）

→ **決算発表直後に最も強く反応**

#### 2. しかし、リターン差は2ヶ月で最大
- **小型株（Q1）の成長率効果**（Q4高成長 - Q1低成長）:
  - 1週間: +1.75%
  - 1ヶ月: +1.87%
  - **2ヶ月: +2.63%（最大）**

→ **効果は時間をかけて拡大**

#### 3. 既存分析（3ヶ月）との比較
- **3ヶ月**: +3.85%（既存分析、20260221_1330より）
- **2ヶ月**: +2.63%（今回）

→ **最適保有期間は2～3ヶ月**

#### 4. 時価総額による違い（1ヶ月の成長率効果）
- **小型株（Q1）**: +1.87%
- **中型株（Q2）**: +1.93%
- **中型株（Q3）**: +1.78%
- **大型株（Q4）**: +1.32%

→ **小型・中型株で効果が強い**

```

【期待リターン】

```

#### リバランス頻度
- **月次リバランス**: 取引コストが低い場合
- **四半期リバランス**: 取引コスト重視の場合

## 学んだこと

### 1. 相関とリターン差は別物
- **相関係数**: 線形関係の強さ（1週間が最高）
- **リターン差**: 実際の利益の大きさ（2ヶ月が最大）
- → **両方を確認する必要がある**

### 2. 初期反応 vs 持続的な再評価
- **1週間**: 決算発表直後の即座の反応
- **2～3ヶ月**: 情報が伝播し、徐々に価格が調整される
- → **小型株は再評価に時間がかかる**

### 3. 時価総額の重要性
- **小型株**: 2ヶ月で+2.63%の効果
- **大型株**: 2ヶ月で+1.30%の効果
- → **ファクターの効果は時価総額に大きく依存**

### 4. データの再利用で大幅な高速化
- 既存の分析結果（CSV）を再利用
- 必要な部分（株価騰落率）のみ再計算
- → **段階的な分析が効率的**
