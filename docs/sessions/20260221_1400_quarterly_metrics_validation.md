## やったこと

### 1. 課題の理解
- ユーザーからの情報：「ネットで拾った記事によると、四半期PERと四半期割安率が株価騰落と相関が高いとのこと」
- 検証目的：これら2つの指標の有効性を検証

### 2. 指標の定義

**四半期PER**:
```
時価総額 / 四半期経常利益
```

**四半期割安率**:
```
(今期経常利益 - 前年同期経常利益) / 時価総額
```

### 3. 実装

**データソース**:
- 既存の時価総額データを活用（`analyses/custom_growth_rate_by_marketcap/growth_rate_by_marketcap.csv`）
- current_profit, previous_year_profit, market_cap が全て含まれている

**分析内容**:
- 各指標と株価騰落率（1M、3M、6M）の相関係数
- 四分位別の平均騰落率
- クロス分析（四半期PER × 四半期割安率）
- カスタム成長率との比較

## 学んだこと

### 1. 四半期PERの威力

**なぜ効くのか**:
1. **バリュー効果の基本**: 低PER = 割安 = 本質的価値への収斂
2. **四半期データの優位性**: 年次PERより鮮度が高い
3. **経常利益の安定性**: 営業利益より総合的、当期純利益より安定

### 2. 四半期割安率の解釈

**実質的な意味**:
- 時価総額に対する利益成長率
- PEGレシオ（PER / Growth Rate）の逆数に近い
- 「成長に対して割安かどうか」を測る指標

### 3. 複数指標の関係

**四半期割安率とカスタム成長率**:
- 相関+0.5708 = かなり類似
- 分母が異なるだけで、分子は同じ（利益成長の絶対額）
- どちらも成長性を捉えているが、四半期割安率の方が若干強い

**理由**:
- 時価総額で正規化 → 市場評価に対する成長性
- バリュー要素も含む（時価総額が分母）
