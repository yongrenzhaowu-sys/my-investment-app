## やったこと

### 1. 課題の理解
- ユーザーからの情報：「ネットの記事によると、カスタム成長率と益利回り(PERの逆数×100)の関係性を利用することで、来期の株価を予測することができる」
- 詳細は不明なので、金融理論に基づいて推測して検証

### 2. 推測した方法

**理論的背景**を元に4つのアプローチを考案：

1. **PEG的スコア** = カスタム成長率×100 / PER
   - PEGレシオ（成長性に対する割安度）

2. **益利回り** = 1/PER × 100
   - バリュー投資の基本

3. **期待リターン** = 益利回り + カスタム成長率×100
   - ゴードン成長モデル

4. **割安度スコア** = 益利回り × カスタム成長率
   - 乗算による相乗効果

### 3. 実装と検証

- 既存の四半期PERデータを活用
- 各スコアと株価騰落率（1M、3M、6M）の相関を分析
- 四分位分析
- クロス分析（益利回り × 成長率）

## 学んだこと

### 1. PEGレシオの威力

**PEG的スコア = 成長率 / PER**:
- 伝統的なPEGレシオの逆数
- 成長性とバリューを融合
- 長期投資（6ヶ月）で特に有効（相関+0.0862）

**理論的背景**:
- PEG < 1: 割安（成長性に対してPERが低い）
- 今回のスコアは高いほど割安

### 2. 益利回りのシンプルな強さ

**益利回り = 1/PER × 100**:
- 実質的に「低PER戦略」と同じ
- 6ヶ月で相関+0.0936（最強）
- シンプルで実装が容易

**発見**:
- 成長率を考慮しなくても、益利回り単独で強力
- バリュー投資の基本の有効性を再確認

### 3. ゴードン成長モデルの実証

**期待リターン = 益利回り + 成長率**:
- 理論的に正しい（ゴードン成長モデル）
- Q4で年率約+11%
- 実務で使える予測式

### 4. 加算 vs 乗算

**加算（期待リターン）**: 相関+0.0598
**乗算（割安度スコア）**: 相関+0.0390

**結論**: 加算の方が有効
- 乗算は極端な値に敏感
- 加算は安定的な予測力
