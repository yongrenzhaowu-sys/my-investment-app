## 重要な発見

### Legacy実装の特徴
1. **リターン率ベース**: `cumulative_capital * (1 + return)` で複利計算
2. **前後5日猶予**: データ欠損に対するロバスト性
3. **9回のリバランス**: `rebalance_dates[:-1]` で最後を除外
4. **税金計算**: 全資本に対する比率で計算

### データの問題
- **2020-10-01**: adjusted_closeが全てNaN
- **原因**: 調整係数が未計算
- **頻度**: 稀だが、リバランス日がこの日に当たると致命的

### パフォーマンス要因
- リバランス頻度の重要性: 年次(+28.52%) vs 週次(-20.05%) = 49%pt差
- データ取得方法: 前後5日猶予により欠損に強い
- リターン計算方式: リターン率ベースがシンプルで安定
