## 📋 実施した修正

### 1. 余力計算の修正

#### 問題
累計売却額の計算で、売却した銘柄の購入額が**二重にカウント**されていた。

```python
# 修正前（間違い）
余力 = 初期資金 - 現在保有額 + 累計売却額
     = 6,711,800 - 6,259,100 + 600,516
     = 1,053,216円  ❌（452,700円が二重計算）
```

#### 解決策
売却済み銘柄の購入時投資額を差し引く。

```python
# 修正後（正しい）
余力 = 初期資金 - 現在保有額 - 売却済み購入額 + 累計売却額
     = 6,711,800 - 6,259,100 - 452,700 + 600,516
     = 600,516円  ✅
```

**修正ファイル**: `src/profit_calculator.py` (calculate_available_capital関数)

## 📐 計算式の整理

### 総資産
```
総資産 = 保有証券 + 現金
       = current_investment + available_capital
```

### 損益
```
損益 = 総資産 - 初期資金
```

### 損益率
```
損益率 = (損益 / 初期資金) × 100%
```

### 余力（現金）
```
余力 = 初期資金 - 現在保有額 - 売却済み購入額 + 累計売却額
     = 初期資金 - 現在保有額 + 税引き後利益
```

## 🧪 検証例

### ユーザーのケース
- **初期資金**: 6,711,800円
- **売却前**: 14銘柄（6,711,800円）→ 余力0円
- **売却**: 1銘柄（購入452,700円 → 売却638,200円、税引き後利益147,816円）
- **売却後**: 13銘柄（6,259,100円）+ 現金600,516円

**計算結果**:
- **総資産**: 6,259,100 + 600,516 = **6,859,616円** ✅
- **損益**: 6,859,616 - 6,711,800 = **+147,816円** ✅
- **損益率**: (147,816 / 6,711,800) × 100% = **+2.20%** ✅
- **余力**: **600,516円** ✅
