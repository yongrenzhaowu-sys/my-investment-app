## 備考

### 週次リバランスの運用方法
1. **毎週月曜日の朝**:
   ```bash
   cd jquants-sector-momo
   python run_pipeline.py --days 60 --top-sectors 3 --top-stocks 10
   ```
2. **推奨銘柄の確認**: `reports/report_latest.json`を確認
3. **保有銘柄との比較**:
   - 保有銘柄が推奨TOP 10に入っていない → 売却候補
   - 推奨銘柄で未保有 → 購入候補
4. **入れ替え実行**: 100株単位で売買

### リスク管理
- **ストップロス**: -10%で損切り推奨
- **利益確定**: +20〜30%で一部利益確定を検討
- **週次チェック**: 必ず毎週月曜日に推奨銘柄を確認

### 税金の考慮
- 短期売買（1年未満）でも、長期保有（1年以上）でも税率は同じ（20.315%）
- 含み益確定時に約20%の税金が発生
- 年間損益を管理（損益通算を活用）
