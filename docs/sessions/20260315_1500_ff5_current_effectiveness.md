## 💡 推奨戦略

### ポートフォリオ構築方針
1. **主力ファクター**: RMW（収益性）
   - 営業利益率、ROE、資産利益率（ROA）が高い企業を選択

2. **補助ファクター**: MKT（市場全体）、WML（モメンタム）
   - 市場全体の上昇トレンドに乗る
   - 過去のリターンが高い銘柄を選択

3. **避けるべきファクター**: CMA（投資効果）
   - 積極投資企業が不利な環境
   - 保守的投資企業の選択は避ける

### 具体的な銘柄選択基準
```python
# 推奨スクリーニング条件
条件1: ROE > 市場中央値（RMWファクター）
条件2: 営業利益率 > 市場中央値（RMWファクター）
条件3: 過去6ヶ月リターン > 市場中央値（WMLファクター）
条件4: 時価総額 > 100億円（SMB無効のため、大型株優位）
```

## 🎓 学んだこと

### ファクター有効性の時間変動
- **長期（全期間）**: MKT、RMWが安定して有効
- **直近12ヶ月**: RMW、MKT、WMLが有効
- **直近3ヶ月**: MKT、RMWが特に強い
- **教訓**: 短期的にはレジーム変化があるが、RMWは一貫して有効

### 無効化したファクター
- **SMB（小型株効果）**: 2024-2025年は大型株優位の相場
- **HML（バリュー効果）**: PBRによるバリュー選択が機能せず
- **CMA（投資効果）**: 積極投資企業が不利

### 日本株市場の特徴
- 収益性（RMW）が最も安定して有効
- モメンタム（WML）も中長期的に機能
- バリュー（HML）は米国と異なり効果が限定的
