# FF5大型グロース戦略の失敗：市場レジームとファクター戦略

**作成日**: 2026-03-19 02:30
**カテゴリ**: ファクター投資、市場レジーム、リスク管理

---

## 🚨 重要な教訓

**結論**: FF5ファクターによる大型グロース戦略は、金利上昇局面では機能しない。ファクターモデルは市場環境（金利、経済サイクル）を考慮しない限り、短期戦略としては不十分。

## 📊 検証結果サマリー

### 戦略仕様
- **期間**: 2021-10-01～2026-03-01（約4.5年、54回リバランス）
- **スクリーニング条件**:
  1. 時価総額上位30%（大型株）
  2. PBR ≧ 2.0（グロース）
  3. 6ヶ月リターン ≧ 中央値（モメンタム緩和）

- **勝率**: 53.7%

## 🔍 失敗要因の詳細分析

### 1. 金利上昇局面でのグロース株の脆弱性

#### 背景
- **2022年**: FRBが急激な利上げを開始（ゼロ金利→4.5%）
- **グロース株の特性**: 将来キャッシュフローに依存、割引率に敏感

#### 影響
- **2022年1月**: -15.36%（最悪月次リターン）
- **2022年通年**: -22.35%（年間リターン）
- **高PBR銘柄**: 将来利益の現在価値が大幅減少

#### 市場データ
```
年次リターン推移:
2021年（4ヶ月）: +5.39%   ← ゼロ金利環境、グロース有利
2022年: -22.35%            ← 急激な利上げ、グロース大幅下落
2023年: -2.59%             ← 高金利継続、回復せず
2024年: -6.65%             ← 引き続き苦戦
2025年: +2.82%             ← わずかに回復
2026年（2ヶ月）: +22.81%  ← サンプル不足
```

### 2. 高バリュエーション条件のリスク

#### 問題点
- **PBR ≧ 2.0**: 極めて高いバリュエーション
- **市場平均PBR**: 日本市場で約1.2-1.5
- **結果**: バリュエーション調整局面で大幅下落

#### 改善案
1. **PBR条件の緩和**: PBR ≧ 1.5程度に引き下げ
2. **動的調整**: 金利環境に応じてPBR閾値を変更
3. **PBRレンジ**: PBR 1.5-3.0などレンジで制限

### 3. モメンタム条件の不十分性

#### 問題点
- **現在**: 6ヶ月リターン ≧ 中央値
- **問題**: 中央値以上は全銘柄の50%が該当、選別力が弱い

#### 改善案
1. **厳格化**: 上位10-20%に限定
2. **複数期間**: 1M/3M/6Mの複合モメンタム
3. **リスク調整**: リターン/ボラティリティでランク付け

### 4. 初期データ不足

#### 問題点
- **計画期間**: 2021-03-01開始
- **実際**: 2021-10-01開始（6ヶ月前のデータ必要）
- **影響**: 実質的なバックテスト期間が4.5年に短縮

## 📈 ファクターモデルの市場レジーム依存性

### FF5ファクターと市場環境

| ファクター | 金利上昇期 | 金利下落期 | 備考 |
|:---|:---:|:---:|:---|
| **市場（Mkt）** | 中立 | 中立 | 全体市場の動き |
| **規模（SMB）** | 不利 | 有利 | 小型株は金利敏感 |
| **バリュー（HML）** | **有利** | **不利** | 金利上昇でバリュー優位 |
| **収益性（RMW）** | 有利 | 中立 | 高収益企業が安定 |
| **投資（CMA）** | 有利 | 不利 | 保守的投資が有利 |

### 今回の戦略（大型グロース）の問題
- **選択**: 大型（反SMB）× グロース（反HML）
- **金利上昇期**: グロース不利 × 大型不利 = **最悪の組み合わせ**
- **結果**: 2022年に-22.35%の大幅下落

---

## 🛠️ 改善戦略の方向性

### 1. 市場レジーム考慮型ファクター戦略

#### アプローチ
```python
# 10年国債利回りで市場レジーム判定
if yield_change > 0.5:  # 金利上昇局面
    strategy = "Large_Value"  # 大型バリュー
elif yield_change < -0.5:  # 金利下落局面
    strategy = "Large_Growth"  # 大型グロース
else:  # 安定期
    strategy = "Balanced"  # バランス型
```

#### 実装要素
- 10年国債利回りの月次変化率
- 3ヶ月移動平均でスムージング
- レジーム切り替えにヒステリシスを導入（頻繁な切り替え防止）

### 2. 動的PBR条件

#### 従来（固定）
```python
condition = (df['PBR'] >= 2.0)
```

#### 改善（動的）
```python
# 金利に応じてPBR閾値を調整
if yield_level < 1.0:  # 低金利
    pbr_threshold = 2.0  # グロース許容
elif yield_level < 2.0:  # 中金利
    pbr_threshold = 1.5  # 中程度
else:  # 高金利
    pbr_threshold = 1.2  # バリュー寄り

condition = (df['PBR'] >= pbr_threshold)
```

### 3. モメンタム条件の強化

#### 従来（中央値以上）
```python
return_threshold = df['Return_6M'].median()
condition = (df['Return_6M'] >= return_threshold)
```

#### 改善（上位20%）
```python
return_threshold = df['Return_6M'].quantile(0.80)
condition = (df['Return_6M'] >= return_threshold)
```

#### さらに改善（複合モメンタム）
```python
# 1M/3M/6M全てで上位30%
condition = (
    (df['Return_1M'] >= df['Return_1M'].quantile(0.70)) &
    (df['Return_3M'] >= df['Return_3M'].quantile(0.70)) &
    (df['Return_6M'] >= df['Return_6M'].quantile(0.70))
)
```
