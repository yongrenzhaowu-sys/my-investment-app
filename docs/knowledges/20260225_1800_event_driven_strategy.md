## 🚨 ルックアヘッドバイアスの発見と修正

### 初回バックテストの問題（バイアスあり）

**誤ったロジック**:
```python
# その月に決算発表があった銘柄を取得
disclosed_this_month = df[df['year_month'] == current_month]

# その決算データでスクリーニング ← 未来参照！
latest_data = disclosed_this_month.groupby('code').last()

# エントリー: 月初 ← 決算発表より前！
entry_date = current_month_start  # 例: 2017-07-01
```

**問題点**:
- 7月1日に「7月の決算データ」を使って購入（物理的に不可能）
- 未来のデータを使って過去の意思決定をしている

### 修正後のロジック（バイアスなし）

**正しいロジック**:
```python
# 月初時点で利用可能なデータのみ（disclosed_date < 月初）
available_data = df[df['disclosed_date'] < current_month_start]

# 前回までの決算データでスクリーニング
latest_data = available_data.groupby('code').last()

# エントリー: 月初
entry_date = current_month_start
```

**修正のポイント**:
- 月初時点で実際に利用可能なデータのみを使用
- 未来参照を完全に排除

## 学び

### 1. タイミングが重要

**教訓**: 決算発表のタイミングでエントリーすることで、カスタム成長率の効果を最大化できる

- ❌ 3ヶ月リバランス: +12.28%（タイムラグあり）
- ✅ 月次リバランス（修正後）: +21.21%（タイミング最適化）

### 2. 静的分析と動的戦略の乖離

**静的分析**: 決算開示後1ヶ月で+1.87%
**動的戦略**: 年率+21.21%（月次複利+1.77%）

→ 静的分析では過小評価。複利効果と銘柄選択の組み合わせが重要

### 3. 小型株×高成長率の有効性

- 小型株は情報伝播が遅い
- 高成長率は将来期待を反映
- 決算発表後に株価調整が進む

→ この組み合わせが最も効果的

### 4. 簡易版でも十分な精度

- 日次管理は複雑
- 月次集計でも高リターンを実現
- 実装の簡易さとリターンのトレードオフを検討すべき

### 5. 市況フィルターは万能ではない ⚠️

**教訓**: MDDを削減するフィルターは、リターンも削減する

**検証結果**:
- 200日MAフィルター: MDD改善（-31.32% → -15.56%）だが年率大幅低下（+21.69% → +5.61%）
- モメンタムフィルター: MDD小幅改善（-31.32% → -28.27%）だが年率低下（+21.69% → +12.01%）
- **全てのフィルターでシャープレシオが悪化**

**理由**:
- タイミングリスク（市況悪化時に離れすぎる）
- 機会損失（市況良化時に乗り遅れる）
- サンプル数減少（通過率50%前後で統計的優位性が損なわれる）

### 6. ボラティリティターゲティングが最優秀 ✅

**教訓**: リスク管理は市況ではなく、ボラティリティベースで行うべき

**検証結果（Target15_LB3）**:
- **シャープレシオ改善**: 1.137 → **1.213** (+0.076)

- **リターン適度に維持**: +21.69% → +18.17% (-3.52%のみ)
- **機会損失が少ない**: 平均ポジション91.9%

**理由**:
- 動的調整（全期間でポジションを持つ）
- リスクベース管理（市況ではなくボラティリティ）
- 適応性（ボラティリティ高い時は縮小、低い時は拡大）
- 機会損失が少ない（平均ポジション91.9% vs 市況フィルター56%）

**推奨設定**:
- ターゲットボラティリティ: 年率15%

- ポジションサイズ: 20%〜100%

**ルックバック3ヶ月の優位性**:
