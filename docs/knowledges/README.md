# Knowledge Base

## 概要
このディレクトリには、日次自動化で得られた**全ての知見**を保存します。
成功・失敗を問わず、全ての分析から学びを抽出し、次の改善に活かします。

## 命名規則
```
{YYYYMMDD_HHMM}_{topic}.md
```

例: `20260220_0900_toyota_earnings_analysis.md`

## テンプレート構造

各knowledgeファイルには以下の項目を含めます：

### 1. アイデア要約
- 簡潔な説明（1-2文）
- 出典（RSS URL等）

### 2. 対象銘柄と根拠
- 銘柄コード（解決できた場合のみ）
- 選択理由

### 3. データ取得方法
- J-Quants API使用エンドポイント
- 取得期間
- キャッシュ利用の有無

### 4. バックテスト設定
- 期間（lookback_years）
- 保有期間（holding_days）
- ベンチマーク

### 5. 結果（主要指標）
- ポートフォリオリターン
- ベンチマークリターン
- 超過リターン
- 勝率
- t値

### 6. 学び（次に効くルール）
- 成功の場合: 何が良かったか、再現性はあるか
- 失敗の場合: 何が悪かったか、次の改善案

### 7. 再実行コマンド
- 同じ分析を再現するためのコマンド
- プロジェクトディレクトリへのパス

## 参照優先順位

新しい分析を開始する前に、必ず以下を確認：

1. **docs/knowledges/** 配下の類似トピック
2. **docs/reports/** の直近レポート
3. 広範囲スキャンは必要時のみ（事前に理由と範囲を宣言）

## 注意事項

- APIキーやトークンは**絶対に含めない**
- 秘密情報は環境変数から読み、ファイルに書かない
- 全ての学びを記録する（成功・失敗問わず）
