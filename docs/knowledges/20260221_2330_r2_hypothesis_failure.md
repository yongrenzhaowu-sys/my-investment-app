# 学び: R2仮説の失敗から得た教訓

**日時**: 2026-02-21
**トピック**: 統計的有意性と実用性の乖離

---

## 背景

書籍に記載された「過去3ヶ月の月足最安値でR2 >= 0.98なら次月上昇」という仮説を検証。

---

## 検証結果

### 統計分析
- R2 >= 0.98の銘柄: 平均次月リターン1.06%（比較群0.92%より+0.14%pt高い）
- t統計量2.976（p < 0.05、統計的に有意）

### バックテスト
- 年率リターン: **-31.25%**（壊滅的失敗）
- 総リターン: -97.33%
- 勝率: 8.6%

---

## 重要な教訓

### 1. 統計的有意性 ≠ 実用性

**問題点**:
- p < 0.05は「偶然ではない」ことを示すだけ
- 効果の大きさ（effect size）が重要
- 0.14%ptの差は実用的には無意味

**基準**:
- 実用的な戦略には、最低1～2%ptの差が必要
- 取引コスト（手数料、税金、スリッページ）を考慮すると、さらに大きな差が必要

### 2. 選択ルールの決定的重要性

**問題点**:
- 「R2 >= 0.98の銘柄」と言っても、どう選ぶかで結果が全く異なる
- slope上位選択は、急騰後の暴落を選んでいた

**教訓**:
- 条件を満たす銘柄の中から、どう選ぶかが最重要
- 統計分析は「全体の平均」を見ているが、実際には「選択ルール」が性能を決める

### 3. バックテストの必須性

**問題点**:
- 統計分析だけでは、実際の戦略性能は分からない
- 選択ルール、取引コスト、タイミングなどを全て考慮する必要がある

**教訓**:
- どんな仮説も、必ずバックテストで検証する
- 統計分析 + バックテストの両方を実施
- 統計的に有意でも、バックテストで失敗することがある

### 4. 書籍・論文の情報は鵜呑みにしない

**問題点**:
- 権威ある書籍でも誤りがある
- データマイニング、サンプルバイアス、過学習などの可能性

**教訓**:
- 必ず自分でバックテストして検証
- 異なる期間、異なる市場で再現性を確認
- 理論的な妥当性も検討

---

## 具体的な失敗の原因

### 高R2 × 高slope = 急騰後の銘柄

**メカニズム**:
1. 過去3ヶ月の最安値が急上昇（slope大）
2. R2が高い = 安定したトレンド
3. → 既に急騰した後の銘柄を選択
4. → 次月は反落する可能性が高い

**具体例**:
- 2020年5月: -60.18%の壊滅的暴落
- 2016年初期: -42.75%, -31.97%, -29.78%の連続損失

---

## 今後の指針

### 仮説検証の標準プロセス

1. **統計分析**
   - 全体の傾向を確認
   - 効果の大きさを測定（最低1～2%pt）
   - t検定で有意性を確認

2. **選択ルールの検討**
   - どう選ぶかを慎重に設計
   - 複数の選択ルールを試す
   - 理論的な妥当性を検討

3. **バックテスト**
   - 実際の戦略をシミュレーション
   - 取引コストを考慮
   - 複数期間で検証

4. **最終判断**
   - 統計分析とバックテストの両方で優位性があるか
   - リスク調整後リターン（シャープレシオ）は十分か
   - 実運用可能か（取引機会、流動性など）

### 採用基準

✅ **採用**:
- 統計的に有意（p < 0.05）
- 効果が大きい（最低1～2%pt）
- バックテストで年率+10%以上
- シャープレシオ > 0.5
- 理論的に妥当

❌ **不採用**:
- 統計的に有意でも効果が小さい（< 1%pt）
- バックテストで損失
- 取引機会が少なすぎる
- 理論的に説明できない
