## 各指標の使い分け

### PEG Ratio（成長株向け）

#### 有効な銘柄タイプ
- **グロース株**: IT、バイオ、新興企業
- **成長率が安定**: 過去5年で一貫した成長
- **利益成長継続**: 今後も成長が期待できる

#### 判断基準
| PEG | 判定 | 投資アクション |
|-----|------|---------------|
| < 0.5 | 超割安 | 🟢 **強気買い**（ただし成長率の持続性を確認） |
| 0.5-1.0 | 割安 | 🟢 買い |
| 1.0-2.0 | 適正 | 🟡 保持 |
| 2.0-3.0 | 割高 | 🔴 一部売却検討 |
| > 3.0 | 超割高 | 🔴 **売却検討** |

#### 注意点
- 成長率がマイナスの場合は計算不可 → PEGに頼らない
- 成長率が急激に変化した場合は過去データが参考にならない

---

### EV/EBITDA（バリュー株向け）

#### 有効な銘柄タイプ
- **安定企業**: 製造業、インフラ、公益事業
- **負債を抱える企業**: 時価総額だけでは評価できない
- **M&A検討**: 企業価値の適正評価

#### 判断基準
| EV/EBITDA | 判定 | 投資アクション |
|-----------|------|---------------|
| < 5 | 超割安 | 🟢 **強気買い**（ただし財務健全性を確認） |
| 5-10 | 割安 | 🟢 買い |
| 10-15 | 適正 | 🟡 保持 |
| 15-20 | 割高 | 🔴 一部売却検討 |
| > 20 | 超割高 | 🔴 **売却検討** |

#### 注意点
- 純負債が大きい企業では理論株価がマイナスになる可能性
- 営業利益で代用しているため、減価償却費の多い業種では乖離あり

---

### DCF Proxy（キャッシュフロー重視）

#### 有効な銘柄タイプ
- **安定CF企業**: 通信、電力、不動産
- **成熟企業**: 成長率は低いがCF安定
- **配当株**: FCFから配当を賄える企業

#### 判断基準
| 株価/理論株価 | 判定 | 投資アクション |
|---------------|------|---------------|
| < 0.5 | 超割安 | 🟢 **強気買い** |
| 0.5-0.8 | 割安 | 🟢 買い |
| 0.8-1.2 | 適正 | 🟡 保持 |
| 1.2-1.5 | 割高 | 🔴 一部売却検討 |
| > 1.5 | 超割高 | 🔴 **売却検討** |

#### 注意点
- **CFデータ欠損率が高い**（約56%）→ 計算不可の銘柄が多い
- WACC固定（10%）→ 業種・企業の実態と乖離
- FCFがマイナスの企業は計算不可

---

### Moving Average（タイミング判断）

#### 有効な使い方
- **エントリータイミング**: ゴールデンクロス時に買い
- **エグジットタイミング**: デッドクロス時に売り
- **トレンド確認**: 他指標と組み合わせて判断

#### 判断基準
| シグナル | 状況 | 投資アクション |
|---------|------|---------------|
| ゴールデンクロス | 25日MAが75日MAを上抜け | 🟢 **買いタイミング** |
| 株価 > 両MA | 上昇トレンド継続 | 🟡 保持（押し目で追加買い） |
| 株価 < 両MA | 下降トレンド | 🔴 売却検討 |
| デッドクロス | 25日MAが75日MAを下抜け | 🔴 **売りタイミング** |

#### 注意点
- テクニカル指標のため、ファンダメンタルズと併用必須
- レンジ相場ではダマシが多い

## 実践的な投資判断フロー

### ステップ1: 総合判定とシグナル一致度を確認

**高信頼パターン**（4つ全て一致）:
```
PEG: BUY
MA: BUY
EV/EBITDA: BUY
DCF: BUY
総合: BUY
→ 🟢 **強気買い** または **保持継続**
```

**中信頼パターン**（3つ一致）:
```
PEG: BUY
MA: BUY
EV/EBITDA: HOLD
DCF: (計算不可)
総合: BUY
→ 🟡 買い検討（慎重）
```

**低信頼パターン**（2つ対2つ）:
```
PEG: BUY
MA: SELL
EV/EBITDA: SELL
DCF: BUY
総合: SELL (多数決)
→ ⚠️ **判断保留**（追加調査必要）
```

### ステップ2: 最小理論株価との乖離を確認

**乖離率による判断**:

| 乖離率 | 評価 | 投資アクション |
|--------|------|---------------|
| < -50% | 超割安 | 🟢 **強気買い**（ただし財務リスクを確認） |
| -50% 〜 -20% | 割安 | 🟢 買い |
| -20% 〜 +20% | 適正 | 🟡 保持 |
| +20% 〜 +50% | 割高 | 🔴 一部売却検討 |
| > +50% | 超割高 | 🔴 **売却検討** |

**重要**: 乖離率がマイナス（割安）でも、シグナルがSELLの場合は注意
- 理由: テクニカルが悪化している可能性（下降トレンド）
- 対処: 押し目を待つ、または小額でナンピン

### ステップ3: 理論株価の手法別比較

**3つの理論株価を比較**:

例:
```
現在株価: ¥1,000

PEG理論株価: ¥1,500 (乖離: -33%, 割安)
EV/EBITDA理論株価: ¥800 (乖離: +25%, 割高)
DCF理論株価: ¥1,200 (乖離: -17%, やや割安)

最小理論株価: ¥800 (EV/EBITDA)
総合乖離: +25%
```

**解釈**:
- EV/EBITDA基準では割高
- PEG/DCF基準では割安
- → バリュー投資家には割高、グロース投資家には割安
- → **自分の投資スタイルに合わせて判断**

### ステップ4: 業種特性を考慮

**グロース株（IT、バイオ）**:
- PEG Ratioを重視
- DCFは参考程度（FCFがマイナスのことも多い）

**バリュー株（製造業、インフラ）**:
- EV/EBITDAを重視
- PEGは参考程度（成長率が低い）

**配当株（通信、電力）**:
- DCF Proxyを重視
- FCFから配当を賄えるか確認

## リスク管理と注意点

### 1. データ品質を確認

**必ず確認すべき項目**:

```python
# 分析結果を見るときのチェックリスト
□ エラーメッセージがないか？
□ 異常な理論株価（マイナス、極端に大きい）はないか？
□ CFデータ欠損による計算不可はないか？
□ 成長率がマイナスでPEG計算不可はないか？
```

### 2. セクター集中を避ける

**推奨**:
- 同じセクターの銘柄が50%を超えないようにする
- 総合判定BUYでも、ポートフォリオバランスを考慮

### 3. 短期的なボラティリティに注意

**MAのダマシ対策**:
- ゴールデンクロス直後に買わない → 数日様子見
- デッドクロス直後に売らない → 数日様子見
- 他の指標（PEG、EV/EBITDA、DCF）が一致しているか確認

### 4. 財務リスクを確認

**超割安（乖離率-50%以下）の場合**:
- 自己資本比率 < 20%: ⚠️ 財務リスク高
- 営業利益が減少傾向: ⚠️ 業績悪化
- 負債比率が高い: ⚠️ 倒産リスク

→ **割安には理由がある**。必ず財務データを確認。

## 定期チェックのルーチン

### 月次チェック（毎月1回）

**タイミング**: 月初（前月末のデータで分析）

**やること**:
1. 全銘柄のバリュエーション分析を実行
2. シグナル変化を記録（BUY→SELL等）
3. 乖離率の推移を確認
4. ポートフォリオ全体のバランスを確認

**記録テンプレート**:
```
【YYYY年MM月 バリュエーション分析】

■ シグナル変化
- 銘柄AAAA: BUY → SELL (PEGが2.5に上昇、割高化)
- 銘柄BBBB: SELL → BUY (MAゴールデンクロス)

■ 新規BUYシグナル
- 銘柄CCCC: 乖離率-35%, PEG 0.8 → 買い検討

■ 売却検討
- 銘柄DDDD: 乖離率+45%, EV/EBITDA 18 → 一部利確

■ アクション
- [ ] 銘柄CCCCを買い注文（指値: ¥XXX）
- [ ] 銘柄DDDDを1/3売却（指値: ¥XXX）
```

### 週次チェック（毎週1回）

**タイミング**: 週末

**やること**:
1. MAのみ再計算（株価は日次更新されるため）
2. ゴールデンクロス/デッドクロスの発生を確認
3. 翌週のエントリー/エグジットタイミングを計画

### デイリーチェック（毎日）

**やること**:
- ニュース確認（決算発表、業績修正等）
- 株価変動の確認
- 指値注文の約定確認

## ケーススタディ

### ケース1: グロース株の買いタイミング

**銘柄**: IT企業A（コード: 12345）

**分析結果**:
```
現在株価: ¥2,500

PEG Ratio: 0.8 (BUY)
  - PER: 24
  - 成長率: 30%
  - 理論株価: ¥3,000

MA: HOLD
  - 25日MA: ¥2,480
  - 75日MA: ¥2,450
  - 乖離率(25日): +0.8%

EV/EBITDA: HOLD (12.5)
  - 理論株価: ¥2,400

DCF: (計算不可、FCFマイナス)

総合判定: BUY
最小理論株価: ¥2,400 (EV/EBITDA)
乖離率: +4.2%
```

**投資判断**:
1. **PEG 0.8は割安** → グロース株として魅力的
2. **乖離率+4.2%は適正範囲** → 割高ではない
3. **MAは保持** → トレンドは中立
4. **総合判定BUY** → 買い候補

**アクション**:
- 🟢 **買い**: ¥2,400-¥2,500のレンジで指値
- 目標株価: ¥3,000（PEG理論株価）
- 損切ライン: ¥2,200（-12%）

**リスク**:
- FCFマイナス → キャッシュフロー悪化に注意
- 成長率30%の持続性を確認

---

### ケース2: バリュー株の売却タイミング

**銘柄**: 製造業B（コード: 67890）

**分析結果**:
```
現在株価: ¥5,000

PEG Ratio: 2.8 (SELL)
  - PER: 14
  - 成長率: 5%
  - 理論株価: ¥3,500

MA: SELL (デッドクロス発生)
  - 25日MA: ¥4,950
  - 75日MA: ¥5,050
  - 乖離率(25日): +1.0%

EV/EBITDA: 18.5 (SELL)
  - 理論株価: ¥4,200

DCF: 1.35 (SELL)
  - 理論株価: ¥3,700

総合判定: SELL
最小理論株価: ¥3,500 (PEG)
乖離率: +42.9%
```

**投資判断**:
1. **4つ全てSELL** → 高信頼の売りシグナル
2. **乖離率+42.9%は割高** → 理論株価から大きく乖離
3. **MAデッドクロス** → 下降トレンド入り
4. **総合判定SELL** → 売却候補

**アクション**:
- 🔴 **売却**: 成行または指値¥4,900-¥5,000
- 再エントリー目標: ¥3,500-¥4,000のレンジ

**リスク**:
- 売却後に上昇する可能性（機会損失）
- → 一部利確、一部保持も検討

### ケース3: 判断が分かれる銘柄

**銘柄**: 通信業C（コード: 11111）

**分析結果**:
```
現在株価: ¥3,000

PEG Ratio: 1.5 (HOLD)
  - PER: 15
  - 成長率: 10%
  - 理論株価: ¥3,000

MA: BUY (ゴールデンクロス)
  - 25日MA: ¥2,950
  - 75日MA: ¥2,900
  - 乖離率(25日): +1.7%

EV/EBITDA: 14.8 (HOLD)
  - 理論株価: ¥2,950

DCF: 0.95 (HOLD)
  - 理論株価: ¥3,150

総合判定: HOLD
最小理論株価: ¥2,950 (EV/EBITDA)
乖離率: +1.7%
```

**投資判断**:
1. **3つがHOLD、1つがBUY** → 中立的
2. **乖離率+1.7%は適正** → 割高でも割安でもない
3. **MAゴールデンクロス** → 上昇トレンド入りの可能性
4. **総合判定HOLD** → 既に保有なら継続、新規買いは慎重

**アクション（既に保有の場合）**:
- 🟡 **保持継続**: 売却は不要
- MAが上昇トレンド確認後、押し目で追加買い検討

**アクション（新規買いの場合）**:
- 🟡 **様子見**: ゴールデンクロスが本物か数日確認
- 押し目（¥2,900-¥2,950）で買い検討

## まとめ: 投資判断の優先順位

### 優先度1: シグナル一致度
- 4つ全て一致 → 高信頼、積極的にアクション
- 3つ一致 → 中信頼、慎重にアクション
- 2対2 → 低信頼、判断保留または追加調査

### 優先度2: 乖離率
- -50%以下 → 超割安（ただし財務リスク確認）
- -20%〜+20% → 適正
- +50%以上 → 超割高（売却検討）

### 優先度3: 業種特性
- グロース株 → PEG重視
- バリュー株 → EV/EBITDA重視
- 配当株 → DCF重視

### 優先度4: タイミング
- MA ゴールデンクロス → 買いタイミング
- MA デッドクロス → 売りタイミング
