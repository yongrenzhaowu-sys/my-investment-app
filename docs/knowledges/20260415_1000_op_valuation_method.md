# ナレッジベース: 営業利益バリュエーション法

**作成日**: 2026-04-15
**検証対象**: 日経225銘柄
**検証期間**: 2022-2025年（4年間）
**検証結果**: ✅ 有効

## 仮説

「過去5年間の営業利益が増益基調の会社において、営業利益×10と時価総額の乖離が大きいと、割安と判定できる」

## 理論的背景

### 営業利益×10 = 理論的時価総額

営業利益の10倍を理論的時価総額とする考え方は、以下の前提に基づきます：

1. **PER（株価収益率）の逆数**: 営業利益ベースのPER = 10倍
2. **適正評価**: 営業利益が安定成長する企業の適正PERは10倍前後
3. **割安の定義**: 実際の時価総額が営業利益×10を下回る場合、割安

### 数式

```
割安度スコア = (営業利益 × 10 - 時価総額) / 時価総額
```

- **スコア > 0**: 割安（時価総額が営業利益×10を下回る）
- **スコア = 0**: 適正評価
- **スコア < 0**: 割高（時価総額が営業利益×10を上回る）

### 例

営業利益1,000億円、時価総額8,000億円の場合：

```
割安度スコア = (10,000 - 8,000) / 8,000 = 0.25 (25%割安)
```

## スクリーニング条件

### 1. 対象銘柄

- 日経225銘柄（または時価総額上位225銘柄）
- 流動性が高く、長期投資に適した銘柄

### 2. 増益基調の定義

本検証では**パターンB（直近3年連続増益）**を採用：

```python
# 直近3年連続増益
is_growth_b = (op_values[-1] > op_values[-2]) and (op_values[-2] > op_values[-3])
```

**採用理由**:
- パターンA（5年で4回以上増益）: 該当銘柄が少なすぎる（3銘柄のみ）
- パターンB（直近3年連続増益）: 適度な銘柄数（138銘柄）
- パターンC（CAGR > 0%）: 長期低迷後の回復銘柄も含まれるため不適

### 3. 割安度スコア計算

```python
# 理論的時価総額
theoretical_value = latest_op * 10

# 割安度スコア
valuation_gap = (theoretical_value - market_cap) / market_cap
```

### 4. 選定ルール

- 割安度スコア上位N銘柄を選定（N=5推奨）
- 時価総額データが欠損している銘柄は除外
- 営業利益がnullまたは0の銘柄は除外

## 運用ルール

### リバランス

- **頻度**: 年次（毎年4月）
- **基準日**: 3月末（この日までに公開された財務データを使用）
- **エントリー**: 4月第1営業日の始値
- **エグジット**: 翌年3月最終営業日の終値

### ポートフォリオ構築

- **銘柄数**: 5銘柄（推奨）
- **ウェイト**: 等金額加重
- **リバランス**: 年次（毎年4月）

### リスク管理

1. **ストップロス**: 個別銘柄で-30%の損失が出たら損切り
2. **分散投資**: 最低5銘柄以上に分散
3. **セクター分散**: 同一セクターに集中しないよう注意
4. **定期的なモニタリング**: 四半期ごとに業績をチェック

## 実装上の注意点

### 1. 調整済み株価の正しい使用（CRITICAL）

```python
# ❌ 間違い: AdjC列をそのまま使用
prices['Price'] = prices['AdjC']

# ✅ 正しい: C × AdjFactor
prices['Price'] = prices['C'] * prices['AdjFactor']
```

**理由**: J-Quants APIの`AdjC`列は実際には調整されていない（`AdjC = C`）

### 2. ルックアヘッドバイアス防止

```python
# 各年3月末時点で公開済みのデータのみ使用
reference_dt = pd.to_datetime('2026-03-31')
financials = financials[financials['DiscDate'] <= reference_dt]
```

### 3. エントリータイミング

```python
# t日終値でシグナル → t+1日始値でエントリー
entry_price = entry_data.iloc[0]['O'] * entry_data.iloc[0]['AdjFactor']
```

### 4. 時価総額計算

J-Quants APIには上場株式数データがない場合があるため、代替指標を使用：

```python
# 出来高をプロキシとして使用
market_cap = price * volume * 100  # スケール調整
```

**注意**: 正確な時価総額データが利用可能な場合は、そちらを使用すること

## リスクと注意事項

### ⚠️ 極端な損失

一部銘柄で極端な損失が発生する可能性があります：

- 2023年度: -95.45%の損失を出した銘柄あり
- 2024年度: -89.31%の損失を出した銘柄あり

### ⚠️ 業績悪化リスク

「直近3年連続増益」の条件を満たしても、翌年以降に業績が悪化する可能性があります。

### ⚠️ セクター集中リスク

特定セクター（例: 金融、不動産）に集中する可能性があります。
