## 指標の定義

### 1. PEG的スコア（最強）

$$PEG的スコア = \frac{カスタム成長率 \times 100}{四半期PER}$$

**解釈**:
- **高いほど割安**（成長性に対してPERが低い）
- 伝統的なPEGレシオの逆数に相当
- PEG = PER / 成長率 → 低PEGが割安

**例**:
- 成長率20%、PER10倍 → スコア = 20/10 = **2.0**（高スコア = 割安）
- 成長率5%、PER30倍 → スコア = 5/30 = **0.17**（低スコア = 割高）

---

### 2. 益利回り

$$益利回り = \frac{1}{四半期PER} \times 100$$

**解釈**:
- **高いほど割安**（低PERに相当）
- 配当利回りの利益版
- 時価総額に対する利益率

**例**:
- PER10倍 → 益利回り = **10%**
- PER50倍 → 益利回り = **2%**

---

### 3. 期待リターン（理論的）

$$期待リターン = 益利回り + カスタム成長率 \times 100$$

**理論的背景（ゴードン成長モデル）**:
$$株式の期待リターン = \frac{配当}{株価} + 成長率$$

**解釈**:
- 現在の利益率（益利回り）
- 将来の成長率
- 合計 = トータルリターン

**例**:
- 益利回り8% + 成長率12% = 期待リターン **20%**
- 益利回り2% + 成長率5% = 期待リターン **7%**

---

### 4. 割安度スコア（乗算）

$$割安度スコア = 益利回り \times カスタム成長率$$

**解釈**:
- 益利回りと成長率の相乗効果
- 両方が高いほど高スコア

## なぜPEG的スコアが効くのか？

### 1. 理論的背景：PEGレシオ

**PEGレシオ（Price/Earnings to Growth）**:
$$PEG = \frac{PER}{成長率}$$

**解釈**:
- PEG < 1: 割安（成長性に対してPERが低い）
- PEG > 1: 割高（成長性に対してPERが高い）

**今回のスコア**:
$$PEG的スコア = \frac{成長率}{PER} = \frac{1}{PEG}$$

→ **高いほど割安**（PEGの逆数）

---

### 2. バリューとグロースの融合

**伝統的な投資スタイル**:
- **バリュー投資**: 低PER、低PBR
- **グロース投資**: 高成長率

**PEG的スコア**:
- 両方を考慮した**ハイブリッド指標**
- 「成長性に対して割安かどうか」

**メリット**:
- 高PERでも高成長なら正当化される
- 低成長のバリュートラップを回避

---

### 3. 長期ほど効果が高い

**相関係数の推移**:
- 1ヶ月: +0.0600
- 3ヶ月: +0.0733
- 6ヶ月: **+0.0862**

**理由（仮説）**:
1. **市場の効率性**: 短期は雑音が多い、長期で本質的価値に収斂
2. **成長の実現**: 成長性が実際の業績に反映されるまで時間が必要
3. **再評価**: 市場が成長性を再評価するのに時間がかかる

## 実装上の注意点

### 1. PEG的スコアの制約

**問題**:
- 成長率が負の場合、スコアが負になる
- 赤字企業（PER負）は除外

**今回の対応**:
- 正の成長率のみに絞った（51,467 / 81,473 = 63%）

**代替案**:
- 成長率が負の場合は別グループとして扱う
- 益利回り単独を使う（成長率不要）

---

### 2. 益利回りの計算タイミング

**今回の実装**:
```python
益利回り = 1 / 四半期PER × 100
四半期PER = 時価総額 / 四半期経常利益
```

**課題**:
- 開示日の時価総額を使用 → 情報が織り込まれている可能性

**改善案**:
- 開示日前日の時価総額を使用
- より厳密な未来参照の防止

---

### 3. 期待リターンの解釈

**計算式**:
```
期待リターン = 益利回り + カスタム成長率×100
```

**単位の注意**:
- 益利回り: %単位
- カスタム成長率: 小数（×100で%に変換）

**例**:
- 益利回り10% + 成長率0.15（15%） → 期待リターン = 10 + 15 = **25%**

---

### 4. 異常値の除外

**今回の基準**:
- 益利回り: -50% ~ +50%
- 期待リターン: -100% ~ +100%
- 割安度スコア: -10 ~ +10

**除外割合**:
- 約3.5%（84,456 → 81,473）

**妥当性**:
- 益利回り50%超 = PER2倍未満（極端に低PER）
- 期待リターン100%超（現実的でない）
