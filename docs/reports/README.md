# Daily Reports

## 概要
このディレクトリには、日次自動化の**日次レポート**を保存します。
毎日の実行結果を記録し、進捗と課題を可視化します。

## 命名規則
```
{YYYYMMDD}.md
```

例: `20260220.md`

## レポート構造

各レポートには以下の項目を含めます：

### 1. RSS取得
- 取得成功件数
- 取得失敗件数
- 総エントリー数
- 失敗理由（ある場合）

### 2. アイデア抽出
- 新規抽出件数
- 銘柄コードあり件数
- 平均スコア

### 3. 本日処理
- 選択件数
- 処理成功件数
- 処理失敗件数
- 各アイデアの結果サマリー

### 4. 主要結果
- 最もパフォーマンスの良かったアイデア
- 学びのハイライト
- 改善すべき点

### 5. 明日のTODO
- 次回実行で対応すべき項目
- キューに残っているアイデア数
- システム改善タスク

## 確認頻度

- 毎日の実行後に確認
- 週次でトレンド分析
- 月次で総括レポート作成

## 活用方法

1. **デバッグ**: エラーが発生した日のレポートを確認
2. **改善**: 連続して失敗しているパターンを特定
3. **成功パターン抽出**: 高パフォーマンスのアイデア傾向を分析

## 注意事項

- レポートは**自動生成**される
- 手動編集は推奨しない（トレーサビリティのため）
- 秘密情報を含めない
