## 成功の要因

### 1. 三つの要素の組み合わせ

**ファンダメンタル（理論株価）**:
- カスタム成長率が将来性を正確に予測
- 本質的価値を客観的に評価
- 単なる「安い」ではなく「本当に割安」を識別

**バリュー（割安株選択）**:
- 理論株価 > 現株価の銘柄のみ選択
- 安全マージンを確保
- リスクを抑制

**モメンタム（勢い）**:
- 割安銘柄の中から上昇トレンドの銘柄を選択
- タイミングを最適化
- バリュートラップを回避

### 2. なぜ他の戦略より優れているか

| 比較 | ベースライン | 理論株価×モメンタム |
|------|-------------|-------------------|
| 選択基準 | 低PBR × 高ROE（2要素） | 理論株価 × 割安度 × モメンタム（3要素） |
| 将来性考慮 | なし | カスタム成長率で考慮 ✅ |
| タイミング | なし | モメンタムで最適化 ✅ |
| 年率リターン | +25.61% | **+34.88%** (+9.27%pt) ✅ |

**差分**: +9.27%ptの改善は、10年で資産が1.5倍以上の差になる

## 実装ガイド

### 必要なデータ

1. **価格データ**: 日次終値（adjusted_close）
2. **財務データ**: EPS、BPS、ROE（年次）
3. **予測スコアデータ**: custom_growth_rate、return_6M、quarterly_per

### リバランス手順（年1回、10月初旬）

**ステップ1: データ準備**
```python
# 10月1日時点の最新データを取得
- 各銘柄の最新EPS
- カスタム成長率
- 過去6ヶ月リターン
- 四半期PER
- 現在株価
```

**ステップ2: 理論株価計算**
```python
# 来期EPS予想
next_eps = current_eps × (1 + custom_growth_rate)

# 理論株価
theoretical_price = next_eps × quarterly_per

# 乖離率
divergence = (theoretical_price - current_price) / current_price
```

**ステップ3: 銘柄選択**
```python
# 1. 割安銘柄を抽出（乖離率 > 0）
undervalued = stocks[divergence > 0]

# 2. モメンタム上位20銘柄
selected = undervalued.nlargest(20, 'return_6M')
```

**ステップ4: ポートフォリオ構築**
```python

# 新規20銘柄を均等配分で購入（100株単位）
# 現金5%程度を残す
```

## 重要な学び

### 検証過程での発見

1. **シンプル ≠ 劣る**
   - ベースライン（2要素）より理論株価×モメンタム（3要素）が優秀
   - しかし複雑すぎる指標（R2補正、tanh）は失敗

2. **組み合わせの妙**
   - バリュー単体: 割安だが上がらないリスク
   - モメンタム単体: 高値掴みのリスク
   - **組み合わせ**: 割安で勢いがある = 最強

3. **理論 vs 実践**
   - 学術的に優れた指標が日本株で失敗（tanh、R2補正）
   - 市場特性を理解することが重要

4. **日次MDDの重要性**
   - リバランス時点のMDDは過小評価
   - 真の日次MDDは-20%～-30%程度（推定）
