# 月足最安値R2仮説の検証レポート

**検証日**: 2026-02-21
**ステータス**: ❌ 仮説は誤り（実用不可）

---

## エグゼクティブサマリー

書籍に記載されていた「過去3ヶ月の月足最安値でR2 >= 0.98なら次月上昇」という仮説を検証した結果、**統計的には微弱な優位性があるものの、実際の投資戦略としては壊滅的に失敗する**ことが判明しました。

---

## 仮説の内容

**書籍の主張**:
- 過去3ヶ月の月足最安値に対して線形回帰を実施
- 決定係数（R2）が0.98以上の銘柄
- これらの銘柄は次の月も上昇する

---

## 検証結果

### 1. 統計分析（全銘柄ベース）

**データ**: 2016年1月～2026年1月、約48万サンプル

| R2閾値 | 該当率 | 平均次月リターン | 比較群リターン | 差 | t統計量 | 評価 |
|--------|-------|----------------|---------------|----|---------|----|
| >= 0.98 | 14.39% | **1.06%** | 0.92% | +0.14%pt | 2.976 | ✅ 統計的に有意 |
| >= 0.95 | 22.78% | 1.02% | 0.91% | +0.11%pt | 2.822 | ✅ 統計的に有意 |
| >= 0.90 | 32.37% | 0.99% | 0.91% | +0.08%pt | 2.164 | ✅ 統計的に有意 |
| >= 0.80 | 46.03% | 0.95% | 0.93% | +0.02%pt | 0.593 | ❌ 有意差なし |

**発見**:
- R2 >= 0.98の銘柄は平均次月リターンが1.06%（比較群0.92%より0.14%pt高い）
- 統計的には有意（p < 0.05）
- しかし、効果は極めて小さい（0.14%ptの差）

### 2. バックテスト（実戦シミュレーション）

**戦略**: R2 >= 0.98、slope上位20銘柄、月次リバランス

**期間**: 2016年4月～2025年12月（9.7年間）

| 指標 | 値 |
|------|------|
| 初期資本 | ¥10,000,000 |
| **最終資産** | **¥267,136** |
| **総リターン** | **-97.33%** |
| **年率リターン** | **-31.25%** |
| シャープレシオ | -1.04 |
| 最大DD | -97.37% |
| **勝率** | **8.6%** |

**主要な問題点**:

1. **取引機会が極端に少ない**
   - 2021年～2025年: ほぼ全ての月で銘柄数0
   - R2 >= 0.98の条件が厳しすぎる

2. **初期の連続大損失**
   - 2016年4月～9月: -42.75%, -31.97%, -29.78%の連続損失
   - 資本が急速に減少

3. **壊滅的な暴落**
   - 2020年5月: **-60.18%**の大暴落
   - わずか1ヶ月で資産の6割を失う

4. **勝率が極端に低い**
   - わずか8.6%（月次ベース）
   - ほとんどの月で損失

---

## なぜ統計とバックテストで結果が異なるのか

### 統計分析の結果（+1.06%）

- **全銘柄の平均**: R2 >= 0.98の条件を満たす全68,392サンプルの平均
- 特定の選択ルールなし
- ランダムに選んでも平均的には1.06%のリターン

### バックテストの結果（-31.25%）

- **slope上位20銘柄を選択**: 傾きが最も急な銘柄を選択
- この選択ルールが致命的だった

**問題の本質**:

1. **高R2 × 高slope = 急騰後の銘柄**
   - 過去3ヶ月で急上昇した銘柄を選んでいる
   - これらは急騰後の反落局面にある

2. **バリュートラップ**
   - 最安値が急上昇（slope大）= 既に上がりきった後
   - 次月は反落する可能性が高い

3. **逆張り的効果**
   - 高R2は安定したトレンドを示すが、
   - 最安値の急上昇は、既に天井圏の可能性

---

## 詳細分析

### R2 >= 0.98の銘柄の特徴

**次月リターンの分布**:
- 平均: 1.06%
- 中央値: 0.31%
- 標準偏差: 11.89%（非常に大きい）
- 最大: +555.92%（異常値）
- 最小: -97.94%（ほぼ全損）

**月別発生頻度**:
- 2020年3月（コロナショック時）: 1,741件（最多）
- 2020年5-6月: 1,093件、1,213件
- 急落後の反発局面で高R2が多発

**slope（傾き）の統計**:
- 平均: 91.8
- 中央値: 21.5
- 標準偏差: 1,538.0（極端に大きい）
- 範囲: -41,500 ～ +105,500

→ 極端なslopeを持つ銘柄が多数存在

### バックテストの月次リターン

**2016年（初期の大損失）**:
- 4月: +1.42% → 5月: -11.42% → 6月: -29.78% → 7月: -31.97% → 8月: -42.75%
- わずか5ヶ月で資産が半分以下に

**2020年（壊滅的暴落）**:
- 4月: +17.54%（唯一の大きな勝ち）
- 5月: **-60.18%**（壊滅的損失）

**2021年以降**:
- ほとんどの月で銘柄数0
- 取引機会がほぼ消滅

## 結論

### 仮説の評価: ❌ 完全に誤り

**統計的評価**:
- R2 >= 0.98の銘柄は、平均的には1.06%のリターン（比較群0.92%）
- 統計的には有意だが、効果は極めて小さい（+0.14%pt）
- **実用的価値: なし**

**実戦評価**:
- 年率リターン: -31.25%（壊滅的）
- 総リターン: -97.33%（ほぼ全損）
- 勝率: 8.6%（極端に低い）
- **実用性: 完全に不可**

### なぜ書籍は誤っているのか

1. **統計的な微弱な優位性を過大評価**
   - +0.14%ptの差は実用的には無意味
   - サンプルバイアスやデータマイニングの可能性

2. **選択ルールの重要性を無視**
   - 「R2 >= 0.98の銘柄」と言っても、どう選ぶかで結果が全く異なる
   - slope上位選択は逆効果

3. **リスクを考慮していない**
   - 標準偏差11.89%（極めて大きい）
   - 最大損失-97.94%（壊滅的）

4. **取引コストを無視**
   - 月次リバランスは手数料・税金で利益を圧迫
   - 0.14%ptの優位性は取引コストで消える

## 代替アプローチの検討

### より緩い条件（R2 >= 0.90）

統計分析では、R2 >= 0.90でも統計的に有意（+0.08%pt）

しかし：
- 効果がさらに小さい
- 取引コストで消える
- バックテストも失敗する可能性が高い

### 逆張り戦略（低R2銘柄）

R2が低い = 不安定なトレンド = ボラティリティが高い

これもリスクが高すぎて実用的ではない

## 学びの記録

### 1. 統計的有意性 ≠ 実用性

- t統計量2.976（p < 0.05）でも、効果が0.14%ptでは実用不可
- 取引コストを考慮すると、1～2%ptの差が必要

### 2. 選択ルールの重要性

- 同じ条件（R2 >= 0.98）でも、選択ルールで結果が劇的に変わる
- slope上位選択は、急騰後の暴落を選んでいた

### 3. バックテストの必要性

- 統計分析だけでは不十分
- 実際の投資戦略をシミュレーションしないと真の性能は分からない

### 4. 書籍の情報は検証が必須

- 権威ある書籍でも誤りがある
- 必ず自分でバックテストして検証すべき
