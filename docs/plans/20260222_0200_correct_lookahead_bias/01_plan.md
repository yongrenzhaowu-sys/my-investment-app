# ルックアヘッドバイアスの修正計画

**作成日時**: 2026-02-22 02:00
**目的**: prediction_scores.csvのルックアヘッドバイアスを修正し、正しいバックテストを実施

---

## 発見した問題

- `return_6M`は未来6ヶ月のリターンだった（ルックアヘッド）
- 年率+34.88%は非現実的な結果
- 全ての戦略結果が信頼できない

---

## 修正アプローチ

### フェーズ1: データ検証

**目的**: 既存のprediction_scores.csvの問題点を完全に把握

**実施内容**:
1. return_6Mの計算方法を確認（過去 or 未来）
2. custom_growth_rateの計算方法を確認
3. quarterly_perの計算方法を確認
4. その他の列もチェック

**所要時間**: 30分

### フェーズ2: 正しいスコアデータの生成

**目的**: ルックアヘッドバイアスのない新しいデータを生成

**実施内容**:

#### 2-1. return_6Mの再計算（最重要）

**正しい計算方法**:
```python
# disclosed_date時点での過去6ヶ月のリターン
for each (code, disclosed_date):
    price_at_disclosed = price[disclosed_date]
    price_6m_before = price[disclosed_date - 180days]
    return_6M = (price_at_disclosed - price_6m_before) / price_6m_before
```

**注意点**:
- disclosed_date時点で利用可能な価格のみを使用
- 調整後株価（adjusted_close）を使用
- 欠損値の処理

#### 2-2. custom_growth_rateの確認

**確認事項**:
- どのように計算されているか
- 未来のデータを使用していないか
- 問題があれば再計算

#### 2-3. その他の列の確認

- return_1M, return_3M: 同様に過去のリターンとして再計算
- quarterly_per: 現在の価格と直近EPSから計算（問題なさそう）
- market_cap: 現在の価格と発行済株式数から計算（問題なさそう）

**所要時間**: 1時間

### フェーズ3: バックテストの再実行

**目的**: 正しいデータで全ての戦略を再検証

**実施内容**:
1. 理論株価×モメンタム複合戦略
2. ベースライン（低PBR×高ROE）
3. その他の戦略

**所要時間**: 1時間

### フェーズ4: 結果の分析とレポート

**目的**: 修正後の結果を分析し、実用可能な戦略を特定

**実施内容**:
1. 修正前後の比較
2. 現実的な期待リターンの算出
3. 最終推奨戦略の決定

**所要時間**: 30分
