### 2.2 財務指標計算
- **PBR**: 時価総額 / 自己資本（equity）
  - 時価総額 = close × 発行済株式数（要確認）
  - または: PBR = (close × shares) / equity
- **ROE**: (net_profit / equity) × 100

### 2.3 週次リバランスロジック
1. **リバランス日**: 毎週金曜日の引け時点で銘柄選定
2. **約定タイミング**: 翌営業日（月曜）の寄りで約定（簡易版：終値で代用）
3. **銘柄選定**:
   - PBR四分位Q1（割安）× ROE四分位Q4（高質）
   - 上位20銘柄を等ウェイト
4. **ポートフォリオ更新**:
   - 前週のポートフォリオ全売却
   - 新しい20銘柄を購入（100株単位）

### 2.4 税金計算（損益通算）
```python
# 年内の損益を累積
annual_realized_pnl = 0

# リバランス時
for rebalance_date in rebalance_dates:
    # 売却
    sell_pnl = (sell_price - buy_price) * shares
    annual_realized_pnl += sell_pnl

    # 年末判定
    if is_year_end(rebalance_date):
        if annual_realized_pnl > 0:
            tax = annual_realized_pnl * 0.20315
            cash -= tax
        # 年内損益リセット
        annual_realized_pnl = 0
```

## 3. MDD削減・リターン向上案

### 3.1 リスク管理強化
1. **ポジションサイズ制限**
   - 各銘柄の最大ウェイト: 5% → 3%（20銘柄 → 33銘柄）
   - 分散効果でMDD削減

2. **ボラティリティ調整**
   - 高ボラティリティ銘柄のウェイトを削減
   - σ_i が平均の2倍超の銘柄は除外

3. **ストップロス**
   - 各銘柄が-15%下落したら強制売却
   - ポートフォリオ全体で-10%下落したら現金比率50%に

### 3.2 リターン向上案
1. **モメンタムフィルター追加**
   - 過去3ヶ月リターン > 0% の銘柄のみ選定
   - 割安高質 × モメンタムの3ファクター

2. **流動性フィルター**
   - 出来高上位80%の銘柄のみ対象
   - スリッページ削減

3. **セクター分散**
   - 同一セクター最大3銘柄まで
   - セクター集中リスク回避

4. **リバランス頻度の最適化**
   - 週次 vs 月次 vs 四半期を比較
   - 取引コスト vs リバランス効果のトレードオフ
