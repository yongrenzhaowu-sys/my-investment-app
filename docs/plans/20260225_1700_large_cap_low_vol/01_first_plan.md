**コンセプト**:

**スクリーニング条件**:

**ポートフォリオ構築**:
- **銘柄数**: 20銘柄
- **ウェイト**: 等ウェイト
- **リバランス**: 年次（10月1日）

### 2. ボラティリティの計算

**定義**:
```
Volatility = std(daily_returns[-126:])  # 過去6ヶ月（約126営業日）
```

**計算方法**:
1. 各銘柄の過去6ヶ月の日次リターンを取得
2. 標準偏差を計算
3. 年率換算: `volatility_annualized = volatility_daily × sqrt(252)`

### 4. バックテストロジック

#### ステップ1: 各リバランス日での銘柄選定
```python
for rebalance_date in ['2016-10-01', '2017-10-01', ..., '2025-10-01']:
    # 1. リバランス日時点で利用可能な財務データを取得
    available_data = df[df['disclosed_date'] < rebalance_date]

    # 2. 時価総額の四分位を計算
    latest_data = available_data.groupby('code').last()
    latest_data['marketcap_quartile'] = pd.qcut(latest_data['market_cap'], q=4, labels=['Q1','Q2','Q3','Q4'])

    # 3. 大型株（Q4）を抽出
    large_cap = latest_data[latest_data['marketcap_quartile'] == 'Q4']

    # 4. 過去6ヶ月のボラティリティを計算
    for code in large_cap['code']:
        past_6m_returns = get_returns(code, rebalance_date - 180days, rebalance_date)
        volatility = past_6m_returns.std()
        large_cap.loc[code, 'volatility'] = volatility

    # 5. ボラティリティの四分位を計算
    large_cap['vol_quartile'] = pd.qcut(large_cap['volatility'], q=4, labels=['Q1','Q2','Q3','Q4'])

    # 6. 低ボラティリティ（Q1）を選定
    low_vol = large_cap[large_cap['vol_quartile'] == 'Q1']

    # 7. 上位20銘柄を選定（ボラティリティの低い順）
    selected = low_vol.nsmallest(20, 'volatility')
```
