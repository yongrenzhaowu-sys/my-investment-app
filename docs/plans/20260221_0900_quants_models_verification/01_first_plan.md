# 8つのクオンツモデル検証計画

## 作成日
2026-02-21 09:00

## 概要

出典資料で提示された8つのクオンツモデルについて、現在保有しているデータセットで検証可能なものをすべて検証する。

## 利用可能なデータセット

### 1. 価格データ
- **パス**: `data/curated/jquants/prices/daily_quotes_all.parquet`
- **期間**: 2017年以降
- **レコード数**: 9,148,461行
- **カラム**: date, code, open, high, low, close, adjusted_close, volume, turnover_value
- **計算可能な指標**:
  - ボラティリティ（日次リターンの標準偏差）
  - 出来高回転率（volume / 発行済株式数）※発行済株式数データが必要
  - 株価リターン

### 2. 財務データ
- **パス**: `data/curated/jquants/financials/statements_all.parquet`
- **期間**: 2016年以降
- **レコード数**: 171,943行（年次: 60,649行、四半期: 111,294行）
- **主要カラム**:
  - 基本財務: net_sales, operating_profit, ordinary_profit, net_profit
  - バランスシート: total_assets, equity, equity_ratio
  - Per Share: eps, bps
  - 予想データ: FSales, FOP, FOdP, FNP, FEPS（当期）, NxFSales等（翌期）
  - 配当: DivAnn, FDivFY, NxFDivFY, PayoutRatioAnn
  - 日付: disclosed_date, fiscal_year_end
  - その他: fiscal_quarter (FY/1Q/2Q/3Q)

### 3. 計算可能な財務指標
- **ROE** = net_profit / equity × 100
- **ROA** = net_profit / total_assets × 100
- **PBR** = stock_price / bps
- **PER** = stock_price / eps
- **営業利益率** = operating_profit / net_sales × 100
- **経常利益率** = ordinary_profit / net_sales × 100
- **自己資本比率** = equity_ratio（直接取得可能）
- **売上高成長率** = (net_sales - 前期net_sales) / 前期net_sales × 100
- **利益成長率** = (net_profit - 前期net_profit) / 前期net_profit × 100
- **予想リビジョン** = (FNP - 前回FNP) / 前回FNP × 100

## 8つの戦略の検証可能性評価

### 戦略1: バリュエーション水準と資本効率性指標の有効性モデル
**検証可能性**: ✅ **可能（優先度: 高）**

**内容**:
- 低P/B銘柄: ROEの有効性を検証
- 高P/B銘柄: ROA、ROICの有効性を検証（ROICはデータ不足のため除外）
- EQS、EVSは計算不可（データ不足）

**実装方針**:
1. P/Bを四分位に分割
2. 各四分位でROE、ROAによるポートフォリオ構築
3. パフォーマンス比較（リターン、シャープレシオ）

**必要なデータ**:
- 株価（adjusted_close）
- BPS（bps）
- ROE（net_profit / equity）
- ROA（net_profit / total_assets）

---

### 戦略2: ファクターの複合戦略（クオリティ・バリュー戦略）
**検証可能性**: ✅ **可能（優先度: 高）**

**内容**:
- バリュー: P/B、PER
- クオリティ: ROE、自己資本比率、営業利益率
- 複合戦略: 低PBR × 高ROE（既存分析と類似）

**実装方針**:
1. 単独ファクター: PBR、PER、ROE、自己資本比率、営業利益率
2. 複合ファクター: PBR×ROE、PER×ROE、PBR×自己資本比率
3. パフォーマンス比較

**必要なデータ**:
- 株価
- BPS、EPS
- ROE、自己資本比率、営業利益率

---

### 戦略3: ガバナンスとグロースの複合戦略
**検証可能性**: ❌ **困難（優先度: 低）**

**理由**:
- 日興ガバナンススコアのデータなし
- グロース（売上高成長率）は計算可能だが、ガバナンススコアがないため検証不可

**代替案**:
- グロース単独の有効性検証（売上高成長率、利益成長率）
- 配当性向をガバナンスの代理指標として使用（不完全）

---

### 戦略4: バリュートラップ回避モデル
**検証可能性**: ✅ **可能（優先度: 高）**

**内容**:
- 割安株の中で、バリュートラップを回避
- 選定基準: 業績予想リビジョン、出来高回転率

**実装方針**:
1. 割安株（低PBR）を選定
2. その中で以下でフィルタ:
   - 業績予想リビジョン > 0（上方修正）
   - 出来高回転率 > 閾値（流動性確保）
3. パフォーマンス比較（フィルタあり vs なし）

**必要なデータ**:
- PBR
- 予想データ（FNP）とその履歴（リビジョン計算）
- 出来高（volume）

**注意点**:
- 発行済株式数データがない場合、出来高回転率は計算不可
- 代替案: 出来高の絶対値や対数で代用

---

### 戦略5: 自社株買い・増配候補銘柄の抽出モデル
**検証可能性**: ⚠️ **部分的に可能（優先度: 中）**

**内容**:
- 自社株買い: 予測は困難（履歴データなし）
- 増配: B/P（PBRの逆数）、予想ROE、過去リターン

**実装方針**:
1. 増配候補の予測:
   - 低PBR（割安）
   - 高予想ROE（収益性）
   - 過去6ヵ月リターン > 0（株価上昇）
2. 増配実績の検証:
   - DivAnn、FDivFY、NxFDivFYの増減を確認
   - 予測モデルの精度を評価

**必要なデータ**:
- PBR
- 予想ROE（FNP / equity）
- 過去リターン（株価データ）
- 配当データ（DivAnn、FDivFY、NxFDivFY）

---

### 戦略6: 「ネクスト 150」戦略
**検証可能性**: ❌ **困難（優先度: 低）**

**理由**:
- エクイティスプレッド（EQS）の計算に必要なデータ不足
- 東証プライム150指数の構成銘柄リスト未取得

**代替案**:
- 時価総額上位150銘柄を代用
- ROEやPBRで「次に評価が高まる銘柄」を抽出

---

### 戦略7: スタブ価値（保有株式価値）注目モデル
**検証可能性**: ❌ **不可（優先度: 低）**

**理由**:
- 保有株式データ（子会社株式の時価）なし
- 親会社の時価総額と比較するデータがない

---

### 戦略8: 高ガバナンス・低ボラティリティ戦略
**検証可能性**: ⚠️ **部分的に可能（優先度: 中）**

**内容**:
- ガバナンス: データなし（配当性向で代用）
- ボラティリティ: 計算可能

**実装方針**:
1. ボラティリティの計算（過去60日の日次リターン標準偏差）
2. 低ボラティリティポートフォリオの構築
3. ボラティリティ逆数加重（最小分散ポートフォリオに近似）
4. パフォーマンス比較（等金額加重 vs ボラティリティ逆数加重）

**必要なデータ**:
- 株価（日次リターン）
- 配当性向（PayoutRatioAnn）※ガバナンスの代理指標

## 実装計画

### Phase 1: データ準備（共通）
1. 価格データと財務データの結合
2. 各指標の計算（ROE、ROA、PBR、PER、成長率等）
3. データクリーニング（異常値除外）
4. 月次リバランス日の生成

### Phase 2: 戦略1 - バリュエーション×資本効率性
1. P/Bを四分位に分割
2. 各四分位で以下のポートフォリオを構築:
   - 高ROEポートフォリオ（上位25%）
   - 高ROAポートフォリオ（上位25%）
3. バックテスト実行（2017-2026）
4. パフォーマンス比較（各四分位でROE vs ROA）
5. 知見ファイル生成

### Phase 3: 戦略2 - クオリティ・バリュー複合
1. 単独ファクター:
   - 低PBR
   - 低PER
   - 高ROE
   - 高自己資本比率
   - 高営業利益率
2. 複合ファクター:
   - 低PBR × 高ROE
   - 低PER × 高ROE
   - 低PBR × 高自己資本比率
3. バックテスト実行
4. ファクター有効性の比較（単独 vs 複合）
5. 知見ファイル生成

### Phase 4: 戦略4 - バリュートラップ回避
1. 割安株ポートフォリオ（低PBR上位N銘柄）
2. フィルタ適用:
   - 予想リビジョン > 0
   - 出来高 > 閾値（または対数出来高 > 閾値）
3. バックテスト実行
4. パフォーマンス比較（フィルタあり vs なし）
5. バリュートラップ回避率の検証
6. 知見ファイル生成

### Phase 5: 戦略5 - 増配候補（オプション）
1. 増配候補スクリーニング:
   - 低PBR
   - 高予想ROE
   - 過去6ヵ月リターン > 0
2. 増配実績の確認（DivAnn、FDivFYの増減）
3. 予測精度の評価
4. バックテスト（増配候補ポートフォリオ）
5. 知見ファイル生成

### Phase 6: 戦略8 - 低ボラティリティ（オプション）
1. ボラティリティ計算（過去60日）
2. 低ボラティリティポートフォリオ（下位25%）
3. 加重方式:
   - 等金額加重
   - ボラティリティ逆数加重
4. バックテスト実行
5. リスク調整後リターンの比較
6. 知見ファイル生成

## 注意事項

### 未来参照（Lookahead Bias）の防止
- 財務データは `disclosed_date` 以降のみ使用
- 予想データも同様に開示日ベースで処理
- リバランス日時点で利用可能なデータのみを使用

### 生存者バイアス（Survivorship Bias）
- 現在のデータセットは全期間の全銘柄を含むため問題なし
- ただし、上場廃止銘柄のデータが欠損している可能性あり

### データ品質
- 財務データの欠損値処理
- 異常値の除外（ROE > 100%, PBR < 0 等）
- 四半期決算と年次決算の区別（fiscal_quarter列）

### 計算コストの最適化
- 既存ノートブックと同様、ピボットテーブル化で高速化
- 財務データの事前処理（各リバランス日の最新データを事前計算）
- ベクトル化処理
