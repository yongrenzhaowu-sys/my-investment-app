# 理論株価×モメンタム複合戦略：最適リバランス月の特定

**作成日時**: 2026-02-22 00:00
**目的**: 年1回リバランスにおいて、何月開始が最も有利かを確定する

---

## 背景

**確定戦略**: 理論株価×モメンタム複合戦略
- 年率リターン: +34.88%（10月リバランス）
- リバランス頻度: 年1回
- 保有期間: 365日

**疑問点**:
- 10月リバランスが最適なのか？
- 他の月（1月、4月、7月など）の方が有利ではないか？

---

## 検証アプローチ

### フェーズ1: 全12ヶ月のバックテスト

**目的**: 各月をリバランス月として設定し、パフォーマンスを比較

**実施内容**:
1. 1月リバランス（毎年1月初旬にリバランス）
2. 2月リバランス（毎年2月初旬にリバランス）
3. 3月リバランス
4. ... （12月まで）

**評価指標**:
- 年率リターン
- シャープレシオ
- 最大ドローダウン
- 勝率
- 総リターン

### フェーズ2: 結果の分析

**比較項目**:
1. **リターン重視**: 年率リターンが最大の月
2. **リスク調整後リターン重視**: シャープレシオが最大の月
3. **安定性重視**: 最大DDが最小の月
4. **総合評価**: バランスの取れた月

**季節性の分析**:
- 四半期ごとの傾向（Q1: 1-3月、Q2: 4-6月、Q3: 7-9月、Q4: 10-12月）
- 日本株市場の季節性（決算期、配当月など）

## 予想される結果

### 仮説1: 10月が最適（現状維持）

**根拠**:
- 日本企業の多くは3月決算
- 10月 = 中間決算発表後
- 来期予想が出揃うタイミング

### 仮説2: 4月が最適

**根拠**:
- 4月 = 新年度開始
- 本決算発表後
- 来期計画が確定

### 仮説3: 1月が最適

**根拠**:
- 1月 = 年初効果（January Effect）
- 新規資金流入
- ポートフォリオのリバランス需要

### 仮説4: 大きな差はない

**根拠**:
- 年1回リバランスは長期保有
- リバランス月の違いは誤差範囲
- どの月でも大きな差はない

## 成功基準

### 明確な最適月が特定できる場合

- ある特定の月が他の月より明らかに優れている
- 年率リターンで+5%pt以上の差
- またはシャープレシオで+0.2以上の差

### 大きな差がない場合

- 全ての月で年率+30%前後
- シャープレシオも1.0前後
- → 10月リバランス（現状）を維持
