# 月足最安値R²仮説の検証計画

**作成日時**: 2026-02-21 23:00
**目的**: 「過去3ヶ月の月足最安値でR²≥0.98なら次月上昇」という仮説を検証

---

## 仮説の内容

書籍に記載されている主張：
- 過去3ヶ月の月足最安値に対して線形回帰を実施
- 決定係数（R²）が0.98以上の銘柄
- これらの銘柄は次の月も上昇する

---

## 検証アプローチ

### フェーズ1: データ分析（統計検証）

**目的**: 仮説が統計的に有意か確認

**手順**:
1. 月次データの準備
   - 各月の最安値（low）を集計
   - 2016年1月～2026年1月（約10年分）

2. R²計算
   - 各月末時点で、過去3ヶ月の最安値を使用
   - 線形回帰: y = ax + b（x=0,1,2）
   - R²（決定係数）を計算

3. 条件抽出
   - R² >= 0.98 の銘柄を特定
   - 各月でどれだけの銘柄が条件を満たすか確認

4. 次月リターンの分析
   - R² >= 0.98 の銘柄の次月リターン
   - R² < 0.98 の銘柄の次月リターン（比較群）
   - 統計的有意差の検定（t検定）

5. 統計サマリー
   - 平均次月リターン
   - 勝率（次月リターン > 0の割合）
   - 標準偏差
   - サンプル数

### フェーズ2: バックテスト（実戦検証）

**目的**: 実際の投資戦略として機能するか確認

**戦略ルール**:
- リバランス: 月次（月初）
- 選択基準: R² >= 0.98
- 銘柄数: 上位20銘柄（追加フィルタが必要な場合）
- 保有期間: 1ヶ月

**評価指標**:
- 年率リターン
- シャープレシオ
- 最大ドローダウン
- 勝率
- 月次リターンの分布

---

## 予想される問題点

### 1. R² >= 0.98 は極めて厳しい条件
- 3点（3ヶ月）の線形回帰でR²=0.98以上は、ほぼ完全な直線
- 該当銘柄が極端に少ない可能性
- → 条件緩和（R² >= 0.95, 0.90）も検証

### 2. ルックアヘッドバイアス
- 月末時点で過去3ヶ月のデータを使用
- 次月初に売買（問題なし）

### 3. サバイバーシップバイアス
- 上場廃止銘柄が含まれているか確認
- J-Quantsデータの範囲を確認

### 4. 統計的有意性
- サンプル数が少ない場合、偶然の可能性
- 複数期間での分割検証が必要

## 成功基準

### 仮説が「正しい」場合
- R² >= 0.98の銘柄の平均次月リターン > 0
- 統計的に有意（p < 0.05）
- 勝率 > 50%
- バックテストで年率リターン > 市場平均

### 仮説が「誤り」または「限定的」の場合
- 統計的有意差なし
- または、サンプル数が極端に少ない（月に数銘柄以下）
- または、バックテストで市場平均以下
