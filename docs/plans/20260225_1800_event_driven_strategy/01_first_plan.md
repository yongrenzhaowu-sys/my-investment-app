## 戦略の定義

### イベントドリブン戦略（決算発表ベース）

**コンセプト**:
- **決算発表をトリガー**とするエントリー
- 定期的なリバランスではなく、情報の鮮度を最大化
- 小型株×高成長率で効果を狙う

**スクリーニング条件**:
1. **時価総額**: 下位25%（Q1、小型株）
2. **カスタム成長率**: 上位25%（Q4、高成長）
3. **四半期決算データが存在**

**エントリー・エグジット**:
- **エントリー**: 決算発表日（disclosed_date）の翌営業日
- **エグジット**: エントリーから1ヶ月後
- **ポートフォリオサイズ**: 動的（決算発表のタイミングに依存）

---

## なぜこの戦略か？

### 1. ベース戦略との相関が低い

| 要素 | ベース戦略 | イベントドリブン戦略 |
|------|-----------|---------------------|
| **リバランス** | 年次（10月1日） | 決算発表日 |
| **エントリータイミング** | 定期的 | イベントベース |
| **保有期間** | 1年 | 1ヶ月 |
| **ファクター** | 低PBR×高ROE | 小型株×高成長率 |

### 2. 既存分析との整合性

**静的分析（20260225_1400）**:
- 決算開示日から1ヶ月で+1.87%
- 小型株×高成長率で効果あり

**3ヶ月リバランスの失敗**:
- リバランス日と決算開示日のタイムラグが問題
- → 決算開示日からエントリーすれば解決

### 3. 情報の鮮度を最大化

- **決算発表直後にエントリー**
- 市場が情報を織り込む前に先回り
- 小型株はアナリストカバレッジが薄く、効果が高い

### 3. バックテストロジック

#### ステップ1: 全決算発表日を取得
```python
# 各決算発表日をイベントとして処理
for disclosed_date in df['disclosed_date'].unique():
    # その時点で利用可能な過去の財務データを使用
    available_data = df[df['disclosed_date'] <= disclosed_date]

    # 各銘柄の最新データ
    latest_data = available_data.groupby('code').last()

    # 時価総額・成長率の四分位を計算
    latest_data['marketcap_quartile'] = pd.qcut(...)
    latest_data['growth_quartile'] = pd.qcut(...)

    # 小型株×高成長率を選定
    selected = latest_data[
        (latest_data['marketcap_quartile'] == 'Q1') &
        (latest_data['growth_quartile'] == 'Q4')
    ]

    # エントリー
    for code in selected['code']:
        entry_date = disclosed_date + 1営業日
        exit_date = entry_date + 21営業日（約1ヶ月）
        positions.append({'code': code, 'entry_date': entry_date, 'exit_date': exit_date})
```

#### ステップ2: ポートフォリオ管理
```python
# 各日のポートフォリオを管理
for date in all_dates:
    # エントリー
    entry_today = [p for p in positions if p['entry_date'] == date]
    portfolio.add(entry_today)

    # エグジット
    exit_today = [p for p in portfolio if p['exit_date'] == date]
    portfolio.remove(exit_today)

    # 日次リターン計算
    daily_return = portfolio.calculate_return(date)
```

### 4. 簡易版（月次集計）

複雑な日次管理を避けるため、簡易版を実装：

```python
# 月次でエントリー銘柄を集計

    # エグジット: 翌月初の翌営業日
    # リターン: 1ヶ月保有
```

### ルール
1. ✅ **決算開示日時点で利用可能なデータのみ使用**
   - `disclosed_date <= current_disclosed_date`
   - ただし、同一銘柄の最新データのみを使用
