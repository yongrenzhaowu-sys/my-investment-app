## 目的

ボラティリティターゲティングにレバレッジを組み合わせ、リスクをコントロールしながらリターンを向上させる。

**現在の状況**:
- Target15_LB3: 年率+18.17%, MDD -22.68%, Sharpe 1.213
- ボラティリティ: 14.98%（良好にコントロール済み）
- 平均ポジション: 91.9%

**目標**:
- 年率リターン: +18.17% → +25%以上
- シャープレシオ: 1.213 → 1.2以上（維持または改善）
- MDD: -22.68% → -30%未満（許容範囲内）

---

## レバレッジ戦略の考え方

### 基本コンセプト

**ボラティリティターゲティング + レバレッジ**:
- ボラティリティターゲットを上げることで、実質的にレバレッジを使用
- リスク管理は維持（ボラティリティベース）
- レバレッジは動的に調整（ボラティリティ高い時は低く、低い時は高く）

### アプローチ1: ターゲットボラティリティを上げる

**現在**: ターゲット15% → ポジション平均91.9%

**レバレッジ適用**:
```
ターゲット20% → 平均レバレッジ 1.3倍程度
ターゲット25% → 平均レバレッジ 1.6倍程度
ターゲット30% → 平均レバレッジ 2.0倍程度
```

**利点**:
- ボラティリティベースの動的調整を維持
- ボラティリティ高い時は自動的にレバレッジ削減
- リスク管理が継続的

### アプローチ2: 固定レバレッジ

**設定**:
```
レバレッジ1.5倍: position_size * 1.5
レバレッジ2.0倍: position_size * 2.0
```

**利点**:
- シンプル
- 効果が明確

**欠点**:
- ボラティリティ高い時もレバレッジ維持
- リスク管理が不十分

### 推奨: アプローチ1（ターゲット上げ）

**理由**:
- ボラティリティベースのリスク管理を維持
- 市況に応じて動的にレバレッジ調整
- より安全で効果的

### ルックバック期間

- **推奨**: 3ヶ月（既存の最優秀設定）
- **理由**: 素早い反応、過度な依存回避

### ポジションサイズ上限

**重要**: レバレッジ使用時は上限を設定

```python
# 現在（レバレッジなし）
position_size = clip(position_size, 0.20, 1.00)

# レバレッジあり
position_size = clip(position_size, 0.20, 2.00)  # 最大2倍
```

**理由**:
- 過度なレバレッジを防ぐ
- 実務的な制約（証券会社の規制）
- リスク管理

## リスクと制約

### 1. レバレッジコスト

**現実**:
- 借入金利（例: 年率1% ~ 3%）
- 信用取引手数料
- 証券会社の規制

**影響**:
- リターンが若干低下（年率-0.5% ~ -2%程度）
- シャープレシオへの影響は小さい

**対応**:
- まずコストなしでポテンシャルを確認
- 次にコスト込みで実用性を評価

### 2. MDDの拡大

**問題**:
- レバレッジでMDDが拡大
- Target30では-45%以上の可能性

**対応**:
- Target20やTarget25に制限
- ストップロス（ポートフォリオレベル）の検討

### 3. 実装の制約

**現実**:
- 証券会社のレバレッジ上限（通常2倍～3倍）
- 維持率の管理
- 追加証拠金の可能性

**対応**:
- レバレッジ上限を2倍に設定
- 実務では維持率監視が必要

### 4. ボラティリティの増加

**影響**:
- ポートフォリオボラティリティが増加
- 心理的な負担

**対応**:
- ターゲットを慎重に選択（20% or 25%）
- 投資家のリスク許容度に応じて調整

### 1. シャープレシオの維持

- Target20: -30%前後（許容範囲）

- 平均レバレッジが2倍以下か
- 極端なレバレッジ（>2倍）が頻発していないか

- ベース戦略（+28.52%）を上回るか
