# 営業利益バリュエーション検証（日経225）

## 検証仮説

「過去5年間の営業利益が増益基調の会社において、営業利益×10と時価総額の乖離が大きいと、割安と判定できる」

## 検証ステップ

### 1. データ取得
- 日経225銘柄リストの取得
- 過去5年間の財務データ（営業利益）取得
- 時価総額データ取得
- 株価データ取得（バックテスト用）

### 2. スクリーニング条件定義

#### 増益基調の定義（複数パターンで検証）
- **パターンA**: 5年間で4回以上増益（前年比）
- **パターンB**: 直近3年連続増益
- **パターンC**: 5年間の営業利益CAGR > 0%

#### 割安度の計算
```
割安度スコア = (営業利益 × 10 - 時価総額) / 時価総額
```
- スコアが大きいほど割安
- 例: 営業利益1,000億円、時価総額8,000億円の場合
  - スコア = (10,000 - 8,000) / 8,000 = 0.25 (25%割安)

### 3. バックテスト設計

#### 期間
- 2021-04 ～ 2026-03（5年間）
- リバランス: 年次（毎年4月）

#### エントリー条件
1. 増益基調を満たす
2. 割安度スコア上位N銘柄（N=5, 10, 20で比較）
3. 時価総額データが利用可能

#### タイミング（ルックアヘッドバイアス防止）
- **データ基準日**: 各年3月末時点で利用可能な財務データ
  - 3月決算企業: 前年度の決算（例: 2021年4月エントリーなら2020年3月期）
  - 12月決算企業: 前年12月期
- **エントリー**: 4月第1営業日の始値
- **エグジット**: 翌年3月最終営業日の終値

#### ベンチマーク
- 日経225平均（等金額加重）
- TOPIX

### 4. 評価指標
- 累積リターン
- 年率リターン（CAGR）
- シャープレシオ
- 最大ドローダウン
- 勝率（年次）

### 5. リスク分析
- セクター集中度
- 個別銘柄集中度
- ボラティリティ

## データソース

### J-Quants API
- `/indices/topix/constituents`: 日経225銘柄リスト
- `/fins/statements` or `/fins/summary`: 財務データ（営業利益）
- `/equities/bars/daily`: 株価データ
- `/markets/indices`: 日経225指数データ

### ローカルキャッシュ
- `data/` 配下のparquetファイル（利用可能であれば優先）

## 注意事項

### 🚨 ルックアヘッドバイアス防止
- 各年のエントリー時点で、その時点で公開済みの決算データのみ使用
- 決算発表日を考慮（4月エントリーなら、3月末までに発表された決算のみ）
- 時価総額は3月末時点の値を使用

### 🚨 調整済み株価
- `AdjC_Correct = C × AdjFactor` を使用
- 重複データ除外（同じCode×Dateで最も取引量が多いレコードを採用）

### データ品質チェック
- 営業利益がnullまたは0の銘柄を除外
- 時価総額データが欠損している銘柄を除外
- 異常値チェック（営業利益×10 / 時価総額が極端な値）
