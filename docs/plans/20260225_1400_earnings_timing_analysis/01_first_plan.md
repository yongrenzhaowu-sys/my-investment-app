# 決算発表後の株価反応タイミング分析 - 作業計画

**作成日**: 2026-02-25 14:00
**分析目的**: 低時価総額株式のカスタム成長率と、決算発表日からの期間別株価相関を検証

---

## 背景

### 既存の知見
1. **カスタム成長率は小型株で強く効く**（20260221_1330より）
   - 小型株（Q1）× 高成長率（Q4）で+5.44%（3ヶ月）
   - 大型株では効果がほぼない（+0.46%）

2. **最適保有期間は3ヶ月**（20260221_1100より）
   - 相関係数+0.0296（3ヶ月）
   - 1ヶ月：+0.0225、6ヶ月：+0.0068

### 未解明の問題
- **株価反応のタイミング**: 決算発表後、いつ株価が反応するのか？
  - 1週間以内に織り込まれるのか？
  - 1ヶ月かけてゆっくり反応するのか？
  - 2ヶ月後にも継続するのか？

---

## 分析目的

### 主要リサーチクエスチョン

1. **低時価総額株式において、カスタム成長率と株価の相関が最も高いのはいつか？**
   - 決算発表日から1週間後
   - 決算発表日から1ヶ月後
   - 決算発表日から2ヶ月後

2. **期間別の相関の強さは？**
   - 相関係数の推移
   - 四分位分析（Q4高成長 vs Q1低成長）のリターン差

3. **時価総額による違いは？**
   - 小型株（Q1）
   - 中型株（Q2, Q3）
   - 大型株（Q4）

---

## 分析手法

### 1. データ準備
- **財務データ**: `data/curated/jquants/financials/statements_all.parquet`
  - 四半期決算の経常利益
  - 開示日（disclosed_date）
  - 時価総額計算用（equity, bps）
- **価格データ**: `data/curated/jquants/prices/daily_quotes_all.parquet`
  - 日次株価（adjusted_close）

### 2. カスタム成長率の計算
既存ロジックを再利用：
```
GrowthRate = (Current - Previous) / (Recent4Q_AbsSum)
```

### 3. 時価総額の計算
既存ロジックを再利用：
```
EstimatedShares = equity / bps
MarketCap = adjusted_close × EstimatedShares
```

### 4. 株価騰落率の計算
**営業日換算**:
- **1週間**: 5営業日
- **1ヶ月**: 21営業日
- **2ヶ月**: 42営業日

**計算方法**:
- 起点: 決算発表日（disclosed_date）の翌営業日の株価
- 終点: 起点から指定営業日後の株価
- 騰落率 = (終点株価 - 起点株価) / 起点株価

### 5. 分析内容
#### 5.1 全体の相関分析
- 各期間（1週間、1ヶ月、2ヶ月）での相関係数を算出

#### 5.2 時価総額四分位別の相関分析
- Q1（小型株）、Q2、Q3、Q4（大型株）ごとに相関係数を算出

#### 5.3 成長率四分位別の平均騰落率
- Q1（低成長）、Q2、Q3、Q4（高成長）ごとに平均騰落率を算出
- 特に**小型株×高成長率**のパフォーマンスに注目

#### 5.4 クロス分析
- 時価総額四分位 × 成長率四分位 のヒートマップ

---

## 期待される結果

### 仮説1: 小型株は反応が遅い
- **予想**: 小型株（Q1）では1週間後より1ヶ月後の相関が高い
- **理由**: アナリストカバレッジが薄く、情報の伝播に時間がかかる

### 仮説2: 大型株は即座に反応
- **予想**: 大型株（Q4）では1週間後の相関が最も高い（ただし弱い）
- **理由**: 機関投資家が即座に反応

### 仮説3: 2ヶ月後は効果が減衰
- **予想**: 2ヶ月後の相関は1ヶ月後より低い
- **理由**: 既存の知見（3ヶ月で最適、6ヶ月で減衰）と一致
