## 🔍 スクリーニング条件（Legacy版を踏襲）

### 財務指標
1. **ROE**: 当期純利益 / 自己資本 × 100（%表示）
   - 条件: ROE > 0, ROE <= 100
2. **PBR**: 時価総額 / 自己資本
   - 条件: PBR > 0, PBR <= 50
3. **時価総額**: 株価 × 発行済株式数
   - 条件: 時価総額 > 10億円

### 選定基準
- ROE降順、PBR昇順でソート
- 上位50銘柄を候補
- 上位20銘柄でポートフォリオ構築（等ウェイト）

## 🚨 ルックアヘッドバイアス防止

### 必須チェック項目
1. **財務データの利用可能性**
   - 10月1日時点で、その年の決算データは利用可能か？
   - → 日本企業の決算は3月期決算が多い（5月開示）
   - → 10月1日時点では前期（3月期）の決算データが利用可能

2. **株価データの利用可能性**
   - 10月1日の株価で10月1日にエントリー？
   - → **NO**: 10月1日終値でシグナル → 10月2日始値でエントリー

3. **財務データの鮮度**
   - 10月1日時点で最新の財務データを使用
   - 開示日（DisclosedDate）<= 10月1日のデータのみ使用

### タイミング設計
```
t年10月1日（終値）: スクリーニング実行
                    ↓
t年10月2日（始値）: ポートフォリオ購入（エントリー）
                    ↓
t+1年10月2日（始値）: ポートフォリオ売却（エグジット）
                    ↓
t+1年10月2日（終値）: 新ポートフォリオ選定
                    ↓
t+1年10月3日（始値）: 新ポートフォリオ購入
```
