## 🔧 戦略ロジック

### ステップ1: データ準備
1. **財務データ取得**:
   - 時価総額（MarketCap）、純資産（Equity）、純利益（Profit）
2. **指標計算**:
   - PBR = MarketCap / Equity
   - ROE = (Profit / Equity) × 100
3. **異常値フィルター**:
   - 0 < PBR < 50
   - -100% < ROE < 100%

### ステップ2: 銘柄スクリーニング（毎年10月1日）
1. **PBRランキング**: 全銘柄をPBR昇順でランク付け
2. **ROEランキング**: 全銘柄をROE降順でランク付け
3. **四分位分類**:
   - PBR四分位（Q1=最割安、Q4=最割高）
   - ROE四分位（Q1=最低収益、Q4=最高収益）
4. **ロング候補抽出**:
   - **条件**: PBR四分位 = Q1（割安） **かつ** ROE四分位 = Q4（高質）
   - 上記条件を満たす銘柄から、PBRの低い順に**上位50銘柄**を選定
5. **最終選定**:
   - 上位50銘柄から、PBRの低い順に**20銘柄**を選定

### ステップ3: ポートフォリオ構築（100株単位制限）
1. **目標ウェイト**: 20銘柄を等ウェイト（各5%）
2. **100株単位調整**:
   - 各銘柄の目標投資額 = 初期資本 × 5%
   - 購入株数 = floor(目標投資額 / (株価 × 100)) × 100
   - 実際の投資額 = 購入株数 × 株価
3. **現金残高**: 初期資本 - 実際の投資額合計

### ステップ4: リバランス実行（年次）
- **リバランス日**: 毎年10月1日
- **約定タイミング**: 10月1日の終値で約定（仮定）
- **リバランス処理**:
  1. 前年のポートフォリオを全て売却
  2. 利益確定時に税金（20.315%）を控除
  3. 新たに選定された20銘柄を購入

### ステップ5: 日次パフォーマンス計算
1. **日次リターン**: 各銘柄の日次リターンを計算
2. **ポートフォリオリターン**: 保有株数加重平均
3. **累積リターン**: 日次リターンの累積
4. **日次MDD**: 累積資産の最大ドローダウンを計算
5. **TOPIX比較**: ベンチマークとの超過リターンを評価
