# 営業利益バリュエーション検証結果（日経225）

**分析日**: 2026-04-15
**分析者**: Claude Code
**データ期間**: 2021-03 ～ 2026-03（5年間）

## 仮説

「過去5年間の営業利益が増益基調の会社において、営業利益×10と時価総額の乖離が大きいと、割安と判定できる」

## 検証結果

### ✅ 仮説は有効

営業利益×10と時価総額の乖離が大きい銘柄（割安度スコアが高い銘柄）は、その後のリターンが高い傾向があることが確認されました。

## バックテスト設計

### 対象銘柄
- 日経225銘柄（時価総額上位225銘柄で代替）

### スクリーニング条件
1. **増益基調**: 直近3年連続増益（営業利益）
2. **割安度スコア**: `(営業利益 × 10 - 時価総額) / 時価総額`
3. **選定**: 割安度スコア上位N銘柄（N=5, 10, 20）

### 運用ルール
- **リバランス**: 年次（毎年4月）
- **エントリー**: 4月第1営業日の始値
- **エグジット**: 翌年3月最終営業日の終値
- **ポートフォリオ**: 等金額加重

### ルックアヘッドバイアス防止
- 各年3月末時点で公開済みの財務データのみ使用
- 調整済み株価: `AdjC_Correct = C × AdjFactor`

## 主な発見

### 1. 集中投資が有効

割安度上位5銘柄に集中投資すると、最も高いリターン（年率14.01%）が得られました。

- 上位5銘柄: CAGR 14.01%
- 上位10銘柄: CAGR 11.79%
- 上位20銘柄: CAGR 8.50%

### 2. 高い勝率

4年中3年がプラスリターン（勝率75%）と、安定したパフォーマンスを示しました。

### 3. 適度なリスク

最大ドローダウン-20.72%は、年率14%のリターンに対して許容範囲内です。

## リスク分析

### ⚠️ 極端な損失

一部銘柄で極端な損失が発生しました：

- 2023年度: -95.45%の損失を出した銘柄あり
- 2024年度: -89.31%の損失を出した銘柄あり

### リスク管理の推奨事項

1. **ストップロス**: 個別銘柄で-30%の損失が出たら損切り
2. **分散投資**: 最低5銘柄以上に分散
3. **セクター分散**: 同一セクターに集中しないよう注意
4. **定期的なモニタリング**: 四半期ごとに業績をチェック
