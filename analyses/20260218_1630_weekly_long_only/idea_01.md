## 🔧 戦略ロジック

### 週次リバランス
1. **リバランス日**: 毎週金曜日の引け
2. **約定タイミング**: 翌営業日の寄り（簡易版：金曜終値で代用）
3. **銘柄選定**:
   - その週の最新財務データ使用
   - PBR四分位Q1（割安） × ROE四分位Q4（高質）
   - 上位20銘柄を等ウェイト（各5%）
4. **ポートフォリオ更新**:
   - 前週のポートフォリオ全売却
   - 新しい20銘柄を購入（100株単位）

### 税金計算（損益通算）
```python
# 年内の損益を累積
annual_realized_pnl = 0

for rebalance_week in weeks:
    # 売却益計算
    realized_pnl = (sell_price - buy_price) * shares
    annual_realized_pnl += realized_pnl

    # 年末処理
    if is_year_end(rebalance_week):
        if annual_realized_pnl > 0:
            tax = annual_realized_pnl * 0.20315
            cash -= tax
        # リセット
        annual_realized_pnl = 0
```

## 🚀 MDD削減・リターン向上案

### 案1: ボラティリティ調整
- 高ボラティリティ銘柄を除外（σ > 平均の2倍）
- 予想効果: MDD -5%、リターン -2%

### 案2: モメンタムフィルター
- 過去3ヶ月リターン > 0% の銘柄のみ
- 予想効果: リターン +3%、MDD -3%

### 案3: ストップロス
- 各銘柄 -15%で強制売却
- ポートフォリオ -10%で現金比率50%
- 予想効果: MDD -10%、リターン -1%

### 案4: セクター分散
- 同一セクター最大3銘柄
- 予想効果: MDD -2%、リターン 0%

## ⚠️ 注意点

1. **未来参照の禁止**:
   - t日の財務データは disclosed_date > t を参照しない

2. **年次決算のみ使用（重要）**:
   - 四半期決算（1Q, 2Q, 3Q）は一時的な業績変動が大きい
   - 年次決算（FY）のみ使用することで、年次戦略と同じロジックに統一
   - **修正前**: 全決算使用 → -89.94%リターン（壊滅的）
   - **修正後**: 年次決算のみ → 検証中

3. **取引コスト**:
   - 週次リバランス → 年間約50回 × 20銘柄 = 1000回の取引
   - 手数料・税金の影響大

4. **過剰最適化リスク**:
   - インサンプル最適化に注意
   - アウトオブサンプル検証必須
