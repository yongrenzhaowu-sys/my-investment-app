# 戦略5: 増配候補銘柄の抽出モデル

**作成日**: 2026-02-21 09:30

## 概要

増配候補を事前に予測し、そのポートフォリオのパフォーマンスを検証する戦略です。
出典の8つのクオンツモデルの中で、戦略5「自社株買い・増配候補銘柄の抽出モデル」の増配部分のみを実装します。
自社株買いデータは取得していないため除外します。

## 仮説

増配を行う企業には以下の特徴があると考えられます。

### 増配候補の選定基準

1. **低PBR（高B/P）**: 割安に放置されているが、実は財務が健全
2. **高予想ROE**: 高い収益性を持ち、配当原資がある
3. **過去6ヵ月リターン > 0**: 株価が既に上昇トレンドにあり、企業業績が改善している

### 検証すべきこと

1. 上記3つの指標は、実際の増配実績と相関があるか
2. 増配候補ポートフォリオは、ベースライン（ランダム選定）よりパフォーマンスが良いか
3. 単独ファクター vs 複合ファクターの優位性

## データセット

### 価格データ
- **パス**: `data/curated/jquants/prices/daily_quotes_all.parquet`
- **期間**: 2017年以降
- **使用カラム**: date, code, adjusted_close

### 財務データ
- **パス**: `data/curated/jquants/financials/statements_all.parquet`
- **期間**: 2016年以降（年次決算のみ）
- **使用カラム**: disclosed_date, code, equity, net_profit, bps, DivAnn, FDivFY, NxFDivFY, fiscal_quarter

### 計算指標

1. **PBR**: adjusted_close / bps
2. **B/P**: bps / adjusted_close（PBRの逆数）
3. **予想ROE**: (FNP / equity) × 100（当期純利益予想 / 純資産）
4. **過去6ヵ月リターン**: (price_now - price_6m_ago) / price_6m_ago
5. **配当増減率**: (DivAnn_current - DivAnn_previous) / DivAnn_previous

## ポートフォリオ構成

月次リバランス、各20銘柄

### 1. ベースライン
- **説明**: 低PBR銘柄（B/P上位）をランダムに20銘柄選定
- **目的**: 比較対象として、単純な割安株ポートフォリオのパフォーマンスを測定

### 2. 戦略A: 低PBR銘柄
- **選定基準**: B/P上位20銘柄
- **目的**: 割安株の中で、増配候補を探す基準の有効性を検証

### 3. 戦略B: 高予想ROE銘柄
- **選定基準**: 予想ROE上位20銘柄
- **目的**: 高収益性企業が増配しやすいかを検証

### 4. 戦略C: 過去6ヵ月リターン > 0
- **選定基準**: 過去6ヵ月リターンがプラスの銘柄から20銘柄
- **目的**: 株価上昇トレンドが増配と相関するかを検証

### 5. 戦略D: 複合戦略
- **選定基準**: 低PBR × 高予想ROE × 過去6ヵ月リターン > 0の3条件を満たす銘柄から20銘柄
- **目的**: 複合条件による増配候補の精度向上を検証

## 増配実績の検証

各リバランス日において、選定した銘柄が翌年実際に増配したかを検証します。

### 増配の定義
- t年の年間配当（DivAnn）と、t+1年の年間配当（DivAnn）を比較
- 増配 = (DivAnn_t+1 - DivAnn_t) / DivAnn_t > 0

### 検証指標
- **増配予測的中率**: 選定銘柄のうち、翌年実際に増配した銘柄の割合

## バックテスト設定

### パラメータ
- **初期資本**: 10,000,000円
- **リバランス頻度**: 月次（月末営業日）
- **保有銘柄数**: 20銘柄
- **単元**: 100株
- **税率**: 20.315%（譲渡益税）
- **期間**: 2017-01-01 ~ 2026-02-17

### 評価指標
- 総リターン
- 年率リターン
- 年率ボラティリティ
- 最大ドローダウン（MDD）
- シャープレシオ
- カルマー比
- **増配予測的中率**

## 実装上の注意点

### 未来参照の防止
- 財務データは `disclosed_date` 以降のみ使用
- 配当データも同様に開示日ベースで処理
- t時点のポートフォリオ構築には、t時点で利用可能なデータのみを使用

### 異常値除外
- PBR: 0.01 ~ 50
- ROE: -100% ~ 100%
- BPS > 0
- Equity > 0
- 配当データの欠損値は除外

### 年次決算のみ使用
- `fiscal_quarter == 'FY'` でフィルタ
- 四半期決算は除外

## 期待される成果

1. 増配予測の精度が定量的に測定される
2. 各指標（PBR、予想ROE、過去リターン）の有効性が明らかになる
3. 複合戦略がベースラインを上回るかが検証される
4. 増配候補ポートフォリオの投資パフォーマンスが評価される

## リスクと制約

### データの制約
- 予想ROE（FNP）のデータが欠損している銘柄は除外される
- 配当データ（DivAnn）が欠損している銘柄も除外される
- 新規上場銘柄は過去データが不足するため、選定されにくい

### モデルの制約
- 増配は企業の意思決定であり、財務指標だけでは予測困難
- 特別配当や記念配当は考慮していない
- 配当政策の変更（例：配当性向目標の変更）は反映されない

### バックテストの制約
- 生存者バイアス: 現在のデータセットに残っている銘柄のみが対象
- 流動性: 実際の売買では、流動性の低い銘柄は約定しない可能性がある
- 税金: 譲渡益税のみを考慮し、配当税は未考慮
